# Changelog

## 2026-10-31 — OGE Trainer 0.3.0 / задание №9 (PR #2, в работе)
- Добавлены инженерные уроки после №6 и короткий шаблон будущих ТЗ.
- Исследованы линейные/квадратные прототипы, включая реальные различия ответа: больший корень, меньший корень и сцепленные корни. №85 и №338495 разделены на L4A/L4B после проверки отображаемых конструкций и правильных исходных ответов.
- Добавлена отдельная Fraction-based модель уравнений, обратные конструкции, exact polynomial solver и независимый parser отображаемой строки.
- Реализованы генераторы L1–L3, L4A/L4B, K2, K3, K6 с отдельными политиками выбранного корня, ограничением ручной сложности, подсказками и решениями. После разделения версию генератора повысили до 0.2.0.
- Добавлены отдельный Telegram flow №9, очередность семейств, сохранение попыток и prompt ID; добавлена миграция 0004 для task9 сессий.
- L4A и L4B включены после зелёного GitHub Actions run 17 на генераторе 0.2.0; CI использовал PostgreSQL 17. Всего включено восемь отдельных прототипов; остальные типы остаются выключенными. Production не затрагивался.

## 2026-10-31 — OGE Trainer 0.2.1 (PR #1, в работе)
- Исправлен PostgreSQL SELECT для подсказок; добавлен интеграционный сценарий двух подсказок с проверкой счётчиков и сохранения после создания нового repository.
- Пауза через меню и `/start` теперь оставляет задачу и попытки в БД, но ответы вне экрана тренировки не принимаются; «Продолжить» доступно только для фактически активной сессии.
- Inline-переходы содержат problem ID: повторный callback старого задания не создаёт второй переход. Ответы принимаются только реплаем на актуальное сообщение с условием; ответы, отправленные без reply, отклоняются.
- Исправлен выбор пользователя в callback-переходе (используется автор callback, а не бот-сообщения). Убрана текстовая обработка переходов, не привязанных к задаче.
- Локально: полный набор — 31 passed, 2 PostgreSQL integration tests skipped без `DATABASE_URL`; Ruff и mypy прошли. PostgreSQL-сценарий остаётся обязательным в CI.
- Просмотр разбора теперь завершает самостоятельную попытку; отдельно хранятся число подсказок, первая и вторая попытки, решения, пропуски.
- Ответы и переходы привязаны к ожидаемому problem ID под блокировкой сессии; одинаковый Telegram message ID учитывается один раз. Добавлены PostgreSQL race tests для двойного ответа, next и answer/skip.
- Добавлена сохраняемая очередь типов без повторов короткого цикла и дедупликация недавних fingerprint; ограниченные ошибки одного семейства пропускаются.
- Runtime generation gate теперь проверяет ручные лимиты; decimal renderer сохраняет разрядность видимых операндов, а oracle сверяет исходный отображённый тип.
- Новая migration 0003 хранит исход попытки, подсказки, решение, отбор кандидата и message ID. Миграция не применялась к production.
- Проверки: основной отчёт 250 задач/тип; PR CI будет включать PostgreSQL 17. См. `reports/oge6-0.2.1-quality.json`.
- Два подтверждённых типа с конечной ёмкостью 43/50 остаются выключенными; исключение из порога 200 не включает их автоматически.

## 2026-10-31 — OGE Trainer 0.2 (в работе, feature branch)
- Добавлен точный AST/Fraction генератор №6, отдельные AnswerPolicy, независимый парсер отображённого условия и типоспецифичные генераторы.
- Добавлен реестр 23 каталоговых прототипов; числовые клоны не учитываются как новые структуры.
- 10 включённых генераторов прошли основной прогон по 250 задач на тип и приёмку минимум 200 уникальных корректных вариантов в пределах 1 200 попыток; отчёт содержит операции, диапазоны, точность, ответы, ручную сложность и сравнение с образцами.
- Обратная сумма единичных дробей подтверждена одним образцом, но оставлена выключенной из-за недостаточного числа реалистичных вариантов; отношения/пропорции остаются неподтверждёнными.
- Добавлен тренировочный Telegram flow №6, фиксация выдачи/двух попыток/hint и migration 0002; production Telegram flow не объявляется проверенным до smoke test.
- Фактическая платформа — Render, не Northflank. Изменения не отправляются в main.
