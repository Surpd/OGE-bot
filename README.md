# OGE Trainer

Telegram-тренажёр первой части ОГЭ по математике. Доступны проверенные семейства
№6–14; полный банк и неподтверждённые семейства не заявляются. Задания №1–5 пока не включены.

## Состояние

- Backend: FastAPI + aiogram, HTTPS webhook `/telegram/webhook`, health endpoint `/health`.
- Хранилище: PostgreSQL/Supabase; схема находится в `migrations/`.
- Пользователь регистрируется по Telegram ID. `update_id` защищён уникальным ключом; повторы
  завершённого события игнорируются.
- Секреты задаются переменными окружения. Никогда не копируйте токен старого бота.
- Атлас в `atlas/` описывает кандидатов семейств; сам по себе он не подтверждает готовность задач.

## Локальный запуск

Требуются Python 3.12+ и PostgreSQL 17+.

```powershell
uv sync --frozen --all-extras
Copy-Item .env.example .env
uv run uvicorn app.main:app --reload
```

Заполните `DATABASE_URL`, `TELEGRAM_BOT_TOKEN` и `TELEGRAM_WEBHOOK_SECRET` только в локальном
`.env` или защищённых secrets хостинга. Приложение применяет идемпотентную миграцию при старте.
Telegram webhook устанавливается только после настройки публичного HTTPS URL и секретов.

## Качество

```powershell
uv run ruff check .
uv run mypy app
uv run pytest -q
```

CI запускает эти проверки и интеграционные тесты с PostgreSQL 17.

## Границы релиза

Интерфейс 1.0 использует компактные inline-меню, продолжение сохранённых тренировок
и страницы прогресса по номерам/типам, истории и ошибкам. Для №8/10/12/14 можно
выбрать тип следующей задачи. Марафон и пробники не отображаются до реализации.

Архитектура и совместимость: `specs/TRAINING_ARCHITECTURE.md`. Контракт интерфейса:
`specs/TRAINING_UX_CONTRACT.md`. Математическое оформление, контрольные примеры
и ограничения Telegram: `specs/MATH_PRESENTATION.md`. Порядок выпуска —
`specs/ROADMAP.md`. Mini App и рекомендательный движок не входят в этот этап.
