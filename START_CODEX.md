# Готовое первое сообщение для Codex

Создай с нуля проект **OGE Trainer** — Telegram-бот для тренировки первой части ОГЭ по математике (№1–19). Вся продуктовая спецификация, обновлённый атлас, технический дизайн, правила качества и дорожная карта находятся в приложенном стартовом комплекте `OGE_Trainer_Starter`.

**Прежде чем что-либо создавать или деплоить**, прочитай `AGENTS.md`, `README.md`, `specs/PRODUCT.md`, `specs/ARCHITECTURE.md`, `specs/QUALITY.md`, `specs/HOSTING_SECURITY.md` и `codex/01_FOUNDATION.md`. Выполни **только задачу 01** и не начинай генераторы до проверки первой вехи.

Работай максимально самостоятельно: создавай файлы, конфигурации, тесты и GitHub-репозиторий через свои инструменты. Не поручай мне вручную писать код, добавлять файлы или тестировать задания. От меня могут потребоваться только действия подтверждения OAuth, доступа к сервисам, создания/замены секрета через защищённый интерфейс и согласие на потенциально платные операции. Любая платная операция без явного разрешения запрещена.

Инфраструктура: новый приватный GitHub repo, Python/FastAPI/aiogram webhook, **Northflank Sandbox** (только если бесплатные условия подтверждены), отдельный Supabase. Не использовать прежние Render, VPS и базы My Island/MMT/IslandQuiz. Установи официальный Northflank Skill для Codex, если в твоей среде доступен установщик. Сохраняй весь код и тесты в репозитории. Испорченный legacy `ogebot.zip` не импортируй и не публикуй: в нём есть старый Telegram-токен.

В конце задачи 01 представь: созданный GitHub URL и коммит, результаты CI, реальные ID/URL хостинга и health-check (если удалось развернуть), схему базы, проверку `/start`/повторов webhook/рестарта, расход ресурсов Northflank и все возникшие блокеры. Не объявляй деплой успешным без проверки. **После выполнения остановись** и дождись отдельного задания на математическое ядро.
