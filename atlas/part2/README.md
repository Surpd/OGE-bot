## Происхождение

- **407 задач из источников.** Сохранили ID и ссылки, переформулировали условия с сохранением математических данных, подготовили собственные разборы. В их числе 6 заданий демоверсии, 1 примера из методических материалов, 376 карточек «Решу ОГЭ» и 24 карточек по подборке `sdamgia.online`. Пометка зеркала означает опубликованную атрибуцию, проверка кодов непосредственно в открытом банке ограничена его доступностью. [Демоверсия](https://doc.fipi.ru/oge/demoversii-specifikacii-kodifikatory/2027/ma_9_2027.zip) · [Решу ОГЭ](https://math-oge.sdamgia.ru/test?a=catlistwstat) · [Подборка задач](https://sdamgia.online/oge/matematika)
- **116 авторских тренировочных карточек.** Из них 37 добавлены после проверки математического разнообразия. Авторские условия и доказательства имеют собственные ID и явную пометку. Ссылка в `model_reference` показывает пример семейства, на который опирались при выборе формата.

Критерии шести заданий демоверсии основаны на их официальной шкале. У остальных карточек учебная рубрика с примерами разрешённых ошибок и существенных пропусков. В №22 верный график с неверным или отсутствующим ответом по пересечениям может дать 1 балл. В №24 критерии проверяют ход обоснования и допускают равноценные доказательства. ## Как читать и использовать банк

- Выбор номера из таблицы открывает условия по подтипам. Подсказки, ответ и разбор раскрываются отдельно.
- `tasks.jsonl` содержит по одной полной статической карточке на строку. Фильтр `bank_scope = source_based` даёт выборку из источников. При включении `training_only` доступно по шесть или семь задач на каждый подтип.
- `taxonomy.json` сохраняет идентификаторы семейств и подтипов. `coverage.csv` содержит историю поиска, ссылки и идентификаторы карточек. `coverage_summary.csv` показывает итог по каждому подтипу и число авторских задач, которые можно заменить новыми задачами из источников.
- Путь рисунка указан относительно `atlas/part2/`. Роль `condition` означает рисунок для выдачи вместе с условием. `solution` — для показа при разборе. Время генерации задачи боту не требуется. Для повторного просмотра попытки можно сохранить `task_id` и `content_version`.

В результате проверки подтверждены структура архива, ссылки между реестрами, наличие подсказок и графики, отсутствие идентичных условий в пределах подтипа. Алгебраические ответы и параметрические случаи сверялись вычислительно. Геометрические чертежи построены из математических конфигураций, а числовые ответы перепроверены на выбранных примерах. Оценивание полного доказательства остаётся по рубрике.
