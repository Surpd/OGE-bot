# Задача Codex 01 — безопасный запуск фундамента OGE Trainer

Ты ведущий разработчик нового Telegram-бота ОГЭ по математике. В корне репозитория находятся `AGENTS.md`, `README.md`, `specs/`, `atlas/`. Прочитай их до реализации. Работа полностью с нуля; legacy код не импортировать.

## Сделай самостоятельно
1. Проверь рабочие доступы к GitHub, Northflank и Supabase. Если нет, сообщи **только необходимое действие авторизации**. Не проси пользователя руками создавать папки/конфиги.
2. Создай новый **приватный** репозиторий (если ещё не создан) и структуру Python 3 + FastAPI + aiogram + Pydantic, `pyproject.toml`, lockfile, Dockerfile, `.gitignore`, безопасный `.env.example` без токенов, GitHub Actions CI.
3. Установи/подключи Northflank Skill: https://github.com/northflank/skills/tree/master/skills/northflank, если Codex умеет использовать `$skill-installer` в своей среде. Не считай наличие skill доказательством доступа к платформе.
4. **До создания ресурсов** проверь в Northflank Sandbox доступность бесплатного плана, наличие payment-method requirement, фактический доступный compute и отсутствие автоматического расхода вне бесплатного лимита. Не переходи на платный план и не добавляй карту без согласия.
5. В новом отдельном Supabase создай миграцию для минимальных `users`, `sessions`, `issued_problems`, `attempts`, `telegram_updates`, соблюдай ограничения RLS и backend-only secrets.
6. Подними приложение с `/health`, Telegram webhook `/telegram/webhook`, `/start`, меню и `Продолжить`; реализуй проверку секретного заголовка и `update_id` идемпотентно. **На этом этапе не выдумывай ещё генераторы.**
7. Прогони unit/integration + REST smoke, задеплой в Sandbox (только если бесплатность и авторизация подтверждены), проверь Telegram `/start`, restart и replay duplicate update.
8. Сделай минимальный журнал решений и актуализируй `specs/ROADMAP.md`. Выводи реальные ссылки/ID деплоя только после readback.

## Не делать
- Не переносить старый токен или старые генераторы, не подключать Groq, не делать Mini App, не открывать доступ всем ученикам, не менять My Island/MMT/IslandQuiz.
- Не оплачивать ничего, не обещать production-SLA от Sandbox.

## Критерии приёмки
- CI зелёный, webhook работает и защищён, бот отвечает, состояние хранится в отдельной БД, повторные updates не создают дубли.
- Код в GitHub, лог деплоя/health и понятный отчёт по лимитам Northflank.
- Если Northflank недоступен бесплатно — закончить локальным/CI рабочим приложением и кратким отчётом о блокере; **не притворяться, что деплой состоялся**.
