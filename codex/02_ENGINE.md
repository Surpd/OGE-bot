# Задача Codex 02 — качественный математический движок

Зависит от завершённой задачи 01. Читай `specs/QUALITY.md`, `specs/ARCHITECTURE.md`, `atlas/atlas.json`.

1. Реализуй типизированный контур `Problem`/`Answer`/`RenderBlock`/`Family` без зависимости от Telegram и DB.
2. Реализуй deterministic seed/version, math AST, Fraction/Decimal, строгую нормализацию ответа и ограниченную генерацию.
3. Начни **только** с №6: реальные источники подтипов, включая №314264, №314265, №314127, №314288, №350101 (только как ссылки/структуры, не копии).
4. Сделай минимум 3 подтверждённые конструкции: +/− дробей, ×/÷ дробей, выражения со скобками (если подтверждены), и независимый solver по отображаемому AST.
5. Для каждого семейства требуй ≥200 уникальных вариантов по воспроизводимым seed, ≥10 000 seed тестов, самостоятельный oracle, валидность формата и контроль смысловых повторов.
6. Добавь regression tests из legacy №6 (включая ошибку `a/(b+c)` vs `(a-b)/c`) и глобальный fail-closed/feature flag.
7. Перед выдачей ученикам прогони CI, сохрани coverage matrix с источниками, предельными случаями, неустранёнными пробелами.

Не переизобретай подтипы без источников и не подключай Groq на каждый запрос. Не двигайся к №9 пока «золотой стандарт» генератора №6 не прошёл gate.
