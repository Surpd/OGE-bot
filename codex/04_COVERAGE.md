# Задача Codex 04 — систематическая доработка атласа и новых номеров

Используй `specs/RESEARCH.md`. Для каждого номера выделяй реальные структурные варианты из ФИПИ и «Решу ОГЭ», фиксируй source URL/task ID, математический механизм, формулировку (нормализованную), проверку и исключения. Ни один из 117 кандидатов нельзя считать готовым автоматически.

Сначала №7,8,12,13,11. Затем №15–19 со строгими геометрическими оракулами, затем №1–5 как общий сюжет. Каждую категорию исследовать отдельно, не делать огромную генерацию по номеру. На каждом шаге обновлять atlas.json + coverage matrix, тесты и feature flags, отслеживать число реально подтверждённых, поддержанных и недоступных типов.

Все случаи без надёжной автоматической проверки оставлять выключенными: пользователь **не обязан вручную проверять** каждую задачу.
