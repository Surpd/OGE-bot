# Статус изображений

Пакет импорта формируется из оригинальных доступных файлов чата. Бинарные файлы пока не загружены через GitHub-коннектор.

- references/ — модельный лист 1752×897, бренд-лист 1536×1024, четыре предоставленных референса в их исходном формате, аватар 414×414 и приветствие 640×360 как версии для Telegram.
- poses/source-sheets/ — четыре оригинальных листа 1312×1199; первый наиболее близок к канону.
- poses/variants/ — 16 исходных вырезанных вариантов, около 600×600, пилотные, не HD-мастера.
- poses/candidates/ — 4 предварительно выбранных вырезанных позы, плюс edge-sit и headphones-adjust (оба 1254×1254, PNG RGBA).
- poses/approved/ — пока без бинарных файлов: техническая приёмка не проводилась.

Перенести из пакета с сохранением структуры; проверить manifest.json и SHA-256. Не загружать случайные скриншоты, архив старого кода или личные материалы. Анимации пока вне основной библиотеки, отдельный PR #112.
