# Позы и занятия

Пилоты: дзен, смартфон, пустая табличка над головой, кулачок. Первый лист выбран как ориентир по сходству. Сидит на краю и поправляет наушники — понравившиеся кандидаты, разнообразить мимику.

| Группа | Идеи |
|---|---|
| Повседневность | Сидит на краю, лотос, смартфон, поправляет наушники, кружка, консоль, слушает музыку, потягивается, спит на руках, лежит на боку, кресло, лежит на животе |
| Анализ | Планшет, блокнот, рука у подбородка, показывает влево/вправо/вверх, наклоняется к данным, часы, калькулятор, голографический график, скрещённые руки |
| Жесты | Peace, кулачок, честь, большой палец, OK, пожимает плечами, щелчок, аплодисменты, машет, дай пять, фейспалм, победный жест |
| Взаимодействие | Табличка над головой/перед грудью, показывает смартфон, выглядывает слева/справа/сверху, опирается на облачко, стрелка, кубок, подбрасывает листы |
| Мемы | Парит в лотосе, пиксельные очки, невозмутимость, хватается за голову, откидывается назад, попкорн, абсолют синема, лежит лицом вниз, драматично смотрит вдаль, потирает руки |

Лупу исключить. Не обязательный объём первого релиза. Позы и мимика независимы; разные ракурсы, без постоянной улыбки. Новые мастера генерировать отдельными изображениями в максимальном разрешении.
