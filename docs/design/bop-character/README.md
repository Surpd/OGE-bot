# bop Math — библиотека персонажа

Единое место для материалов персонажа, отдельно от runtime в app/companion и математической логики.

- references/ — исходные референсы, модельный лист, аватар и приветствие.
- poses/candidates/ — понравившиеся пилотные позы, не production.
- poses/approved/ — только отдельно принятые и проверенные ассеты.
- poses/variants/ и poses/source-sheets/ — альтернативы и оригинальные листы.
- emoji/ — цифровая мимика и будущие эмодзи.
- voice/ — исходный словарь v0.1 (250 реплик) и MVP v0.2 (120), по 43 одобренных формулировки.
- DESIGN_RULES.md — актуальные правила, включая разрешение.
- POSE_BACKLOG.md — идеи будущих поз.
- ASSET_INVENTORY.md — статус бинарных материалов и перенос.

Новые решения в DESIGN_RULES.md имеют приоритет над старыми черновиками. Не включать материалы автоматически в приложение, Docker, математические задачи или Telegram. Не добавлять личные данные, токены, ключи и приватные чаты. Анимационный PR #112 остаётся отдельным экспериментом.

На момент создания доступны текстовые спецификации; оригиналы изображений подготовлены для отдельного импорта. Не считать PNG загруженными до проверки наличия. Не использовать фиктивные изображения.
