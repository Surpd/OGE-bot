# bop Math — визуальный MVP и словарь v0.2

Статус: спецификация. 8 PNG ещё предстоит создать, код бота не изменён. Словарь отобран из существующих 250 реплик: 43 одобренные формулировки + 77 черновиков = 120.

## Восемь PNG

| Файл | Поза |
|---|---|
| `peek.png` | Голова и кисти у края нижнего блока, взгляд влево на данные; лёгкий интерес. |
| `neutral.png` | Спокойный расслабленный бюст, лёгкая улыбка, взгляд к собеседнику. |
| `think.png` | Рука у подбородка, задумчивый взгляд влево, без насмешки. |
| `tablet.png` | Держит планшет, изучает показатели; сосредоточенное выражение. |
| `point.png` | Указывает влево; использовать только при наличии реально выделенной цели по направлению жеста. |
| `pleased.png` | Довольная небольшая улыбка и одобрительный прищур. |
| `celebrate.png` | Выразительная искренняя радость, небольшой победный жест; не детская гиперболизация. |
| `support.png` | Открытая ладонь, спокойный взгляд и нейтральная доброжелательная мимика. |

## Размещение

| Экран | Визуал | Правило |
|---|---|---|
| Первое знакомство | Существующая отдельная обложка, не новый PNG-комментарий | Приветствие один раз. |
| Общий прогресс №1–25 | Нижний правый слот: peek, neutral, think, pleased | Нужен содержательный комментарий; без него слот убрать. |
| Прогресс по номеру | Тот же слот: think, pleased, tablet | Вывод по конкретному номеру/типу, не всей математике. |
| Сводка по типам | Тот же слот: think, tablet, point, pleased | point только при видимой выделенной рекомендации. |
| Работа над ошибками | Тот же слот: tablet, support, think | Только сводка или рекомендация, не отдельный ответ/чертёж. |
| Итог тренировки | Тот же слот: neutral, pleased, celebrate, support, think | Один комментарий по реальным итогам; эмоция соответствует результату. |
| Рекомендации (в т. ч. на экране выбора номера) | Тот же слот: point или tablet | Жест указывает влево на выделенную рекомендацию, иначе tablet. |

## Правила

- Единая зона комментария под данными: bop справа, текст слева. Одинаковый якорь у правой и нижней границы зоны на всех карточках MVP. Не перекрывать цифры, сетку и названия типов.
- PNG персонажа отдельно от текста. Облачко рисуется программно. Исходники RGBA, прозрачный фон, рекомендуемый мастер-холст 1024×1024; общий масштаб головы и сопоставимый визуальный вес. Конкретные размеры слота проверить на существующих карточках, не менять их дизайн заранее.
- Стиль карточек сохраняется: кремовый фон, тёмно-зелёная типографика и существующая семантика цветов. bop остаётся оранжево-графитовым акцентом.
- На карточке максимум один персонаж и одно облачко. Если комментария нет, места недостаточно или нужный ассет не готов — не показывать зону или дать полезный текст без персонажа. Не повторять текст облачка отдельным сообщением.
- Обычная переписка — текст и необязательный маленький эмодзи внутри сообщения. Не отправлять PNG или стикеры после каждого ответа. Статусы верно/неверно остаются однозначными. Кастомные эмодзи не равны автоматически установленным реакциям на сообщения ученика; до готовности использовать обычные символы.
- Математические условия, чертежи, разборы, основное меню и активный экзаменационный режим — без персонажа по умолчанию. Итог экзамена пока без специального словаря; не применять тренировочные фразы без проверки.
- Уведомления на старте текстовые, при наличии согласия и соответствующих фактов; картинки и анимации необязательны. Не менять математическую логику и не добавлять новые уведомления ради словаря.
- Выбирать реплику только среди подходящих событию и подтверждённым данным. Если подходящей нет — стандартная обратная связь или молчание. Не объявлять рост без сопоставимых данных; три новых варианта одного типа подряд с первой попытки без помощи — сигнал закрепления конкретного типа, не всей темы.
- Простой анти-повтор: по возможности исключать последние 5 реально показанных реплик; при отсутствии альтернатив можно промолчать или дать обязательный нейтральный статус. Мемные варианты только при соответствующем редком событии. Числовые пороги и решения о рекомендациях брать из действующей логики продукта.
- 43 ранее одобренные формулировки сохранены дословно; 77 отобранных черновиков не считаются утверждёнными. Одобрение текста не означает одобрение любого контекста. Остальные 130 реплик исходного банка остаются резервом.
- Визуальный канон: bop строчными; надпись MATH на худи; татуировка bop на анатомически правой стороне шеи, левая чистая; не зеркалить; цифровой рот и тонкая подбородочная панель; светлые волосы, наушники с X, взрослые пропорции. Не изменять референс.
