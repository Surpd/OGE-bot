# bop Math — словарь и визуальная маршрутизация v0.1

Предлагаемый словарь и матрица размещения. Не внедрено. Одобрение формулировки не означает одобрение условия или частоты.

## Где использовать персонажа

| Экран | Визуал | Условие |
|---|---|---|
| Первые /start и описание | hero | первое знакомство, статичная обложка |
| Главное меню | none | по умолчанию |
| Выбор задания | none_or_optional_png_overlay | только если показана персональная рекомендация |
| Обычная тренировка — ответ | inline_emoji_optional | однозначное событие; не обязательно на каждый ответ |
| Подсказка | inline_emoji_optional | по запросу; подсказка остаётся главным содержанием |
| Условия, рисунки, математический разбор | none | всегда; комментарий может быть в отдельном интерфейсном контексте, не на чертеже |
| Общий прогресс | optional_png_overlay | есть интерпретация или следующий шаг |
| Прогресс номера/типа | optional_png_overlay | выявлено затруднение, улучшение или рекомендация |
| Работа над ошибками | optional_png_overlay | на сводке, не на каждой ошибочной задаче |
| Итог тренировки | optional_png_overlay | содержательный итог, эмоция соответствует фактам |
| Экзаменационный режим | none | пока идёт решение, не выдавать обратную связь или подсказки |
| Результаты экзамена | optional_png_overlay | после завершения, отдельные критерии экзамена; словарь тренировок не применять автоматически |
| Уведомление | text_default | картинка лишь для отдельно утверждённых случаев |

## Варианты компоновки PNG

Выбор PNG-композиции зависит от свободного пространства и привязки к данным, а не только от эмоции. Рекомендательные указатели допустимы только если нужная область фактически видна, иначе текст без указательного жеста. Один комментарий на карточке, а не персонаж у каждого показателя.

- **welcome:** hero: отдельное приветственное изображение, не использовать как аватарку
- **progress:** side_look: портрет у боковой границы с направленным взглядом; peek: голова и кисти над краем самостоятельного блока комментария, не над сеткой номеров; bottom_comment: небольшой бюст рядом с облачком под данными; none: без персонажа
- **recommendation:** point: отдельные левый и правый ассеты; привязка к реальному выделенному блоку; tablet: если рекомендация не привязана к конкретной строке; none: без персонажа
- **summary:** bottom_comment: эмоция соответствует итогам; cheer: более крупная поза только при значимом результате; tablet: сложный результат и следующий шаг; none: если нечего добавить
- **notification:** none: текст по умолчанию; banner: отдельный горизонтальный шаблон для утверждённых событий
- **chat:** none; inline_emoji: внутри имеющегося сообщения бота; не отдельный стикер и не гарантированная кастомная реакция на сообщение ученика

## Правила

- Эмоция — семантическое состояние, эмодзи — компактный знак в переписке, PNG-поза — отдельный отрендеренный ассет. Не обещать, что все комбинации уже нарисованы.
- В одном событии максимум один фирменный визуальный акцент; системные символы и математические данные не считаются украшением.
- Отдельная библиотека поз с метаданными направления взгляда/жеста, видимости татуировки и якоря размещения. Не отражать по горизонтали.
- Не подменять фактическую обратную связь шуткой. Не утверждать освоение темы или рост без данных. Не делать вывод о причинах математической ошибки без подтверждения.
- Если ассет отсутствует, данных мало или композиция не позволяет размещение, использовать обычный текст или молчание, а не случайную картинку.
- Мемы редкие; не направлять шутки на школьника; не использовать юмор при выраженном расстройстве. Не утверждать частотность до теста на аудитории.
- Не считать обычные чат-ответы, карточки и уведомления одним пулом. Отдельный анти-повтор, общий учёт недавно показанных реплик. Событие и условия имеют приоритет над случайным выбором.
- Не генерировать реплики или персональные картинки через внешний ИИ на лету; не хранить индивидуальные PNG пачками.

## Условия по событиям

**session_perfect** — Тренировка завершена; все задания верны и решены самостоятельно с первой попытки; подсказок и разборов не было.
Канал: `summary`; эмоция: `joy`; поза: `cheer`.

**session_perfect5** — Ровно пять заданий; все пять решены верно с первой попытки самостоятельно, без помощи.
Канал: `summary`; эмоция: `joy`; поза: `cheer`.

**session_strong** — Завершённая тренировка с высоким результатом по действующим критериям продукта; не вывод о владении всей темой.
Канал: `summary`; эмоция: `approval`; поза: `cheer`.

**session_recovery** — В одной тренировке после зафиксированных ошибок ученик самостоятельно решил новые сопоставимые задания этого типа; есть реальный камбэк.
Канал: `summary`; эмоция: `approval`; поза: `lean`.

**session_hard** — Тренировка завершена; есть несколько ошибок или значительная потребность в помощи; не использовать при выраженном расстройстве ученика шутки.
Канал: `summary`; эмоция: `thoughtful`; поза: `tablet`.

**session_mixed** — Результаты тренировки неоднородны; есть и самостоятельные решения, и ошибки/помощь.
Канал: `summary`; эмоция: `thoughtful`; поза: `tablet`.

**session_done** — Тренировка действительно завершена; нейтральный результат, более конкретный комментарий не требуется.
Канал: `summary`; эмоция: `calm`; поза: `lean`.

**progress_up** — Сопоставимые результаты в достаточных выборках по одному и тому же типу/номеру показывают улучшение по действующему правилу продукта.

**progress_independent_up** — Доля самостоятельных решений выросла на сопоставимых выборках, подтверждено метрикой продукта.

**progress_hints_down** — При сопоставимых заданиях потребность в подсказках снизилась, качество не ухудшилось.

**progress_uneven** — Есть достоверное различие между показателями типов; карточка выделяет соответствующие типы.

**progress_repeat_error** — Повторяющееся затруднение обнаружено по действующим правилам; соответствующий тип выделен.
