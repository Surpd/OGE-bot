# «Твой прогресс» — визуальный референс для Telegram

**Статус: утверждённое направление оформления, не production-код.** Этот каталог создан для передачи референса и задания Codex. Он ничего не меняет в работе бота.

![Референс с 25 номерами](preview_25.svg)

## Файлы

- [preview_25.svg](preview_25.svg) — одобренное компактное оформление, которое поддержит будущие №1–25.
- [preview_19.svg](preview_19.svg) — то же оформление с текущими №1–19.
- [reference_renderer.py](reference_renderer.py) — работающий прототип Pillow: генерирует PNG по числовым данным в памяти, без ImageGen и API.
- [IMPLEMENTATION.md](IMPLEMENTATION.md) — техническое задание Codex с путями до текущих production-модулей и проверками.

SVG-файлы здесь нужны **только для просмотра референса прямо на GitHub**. Сам Telegram-бот должен создавать **PNG через Pillow**. Запуск reference_renderer.py воспроизводит растровые PNG для 19 и 25 номеров.

На иллюстрациях только **вымышленные** Вася/@vasya и демонстрационные цифры (12 верно, 14 задач с ответом, 86%, 126 пропусков). Реальных данных учеников нет.

## Непереговорные детали дизайна

1. Светлый тёплый фон, графитовые шрифты, сдержанные градиентные акценты от красного (низкий результат) через янтарный к зелёному (100%). Никакого случайного фиолетового, кубков, аватарок-персонажей и тяжёлых карточек.
2. В шапке одна короткая строка аккаунта (имя и, при наличии, username), ниже только **«Твой прогресс»**. Нельзя писать «Вася / Твой прогресс, Вася» или добавлять «ОГЭ / математика / личная статистика».
3. Сводка: успешность, количество верных, количество пропущенных. Без изменений в правилах подсчёта.
4. Результаты: пять колонок × 4 строки для 19 номеров либо × 5 строк для 25. Все плитки **одной геометрии**: слева №N и correct/answered_tasks, справа процент или «—». Никаких отдельных стилей для ячеек без процентов.
5. При answered_tasks = 0 показывать 0/0 и «—», а не ложные 0%. При answered_tasks < 5 процент предварительный: допустим мягкий цвет числа, но не статус освоения; цвет номера должен оставаться нейтральным. После 5 ответов можно оценочно окрашивать номер. Плавность цвета не меняет смысл метрик.
6. PNG — статичное изображение. Интерактивные Telegram-кнопки остаются **под** ним, а не внутри картинки.

## Локальная проверка

Из корня репозитория, в установленном окружении проекта:

    python docs/design/progress-dashboard/reference_renderer.py

Команда создаёт PNG с 19 и с 25 номерами рядом с исходником. Функция render_progress_png(display_name, username, per_task, skipped, task_count) возвращает байты без временных файлов. Pillow уже есть в pyproject.toml; Dockerfile содержит fonts-dejavu-core.

**Не копировать прототип целиком в production.** Его данные демонстрационные. Реальный способ интеграции со штатными training_insights, progress_keyboard, image transport и тестами описан в [IMPLEMENTATION.md](IMPLEMENTATION.md).
Ветка подключает утверждённый макет к Telegram. Актуальные PNG в мобильном размере:

[частичный](../../../reports/previews/progress-partial-360.png),
