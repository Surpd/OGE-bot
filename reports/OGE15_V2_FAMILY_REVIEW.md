# OGE15 V2. Матрица просмотра условий

Просмотрен один сгенерированный текст и разбор каждого семейства из пробы 0–63.
Для всех 384 полных комплектов генерация прошла встроенные независимые oracle.
Оригиналы задач в этом проходе не пересверялись. Связь с источниками остаётся
в регистрациях адаптеров и в [карте покрытия](../specs/OGE1_5_COVERAGE.md).
Число вариантов и повторов см. в [отчёте по разнообразию](OGE15_V2_DIVERSITY.md).
Проверки ниже описывают доступные ученику данные и способ решения, а не полную
приёмку банка.

| Семейство | Видимые данные и контроль решения | Ограничение или замечание |
|---|---|---|
| TYRES-TABLE-EXTREME | В выбранном столбце сравнить ширины непустых строк | Часто получается одна и та же наибольшая ширина |
| TYRES-SIDEWALL | Ширина × процент из маркировки | Требуется расшифровка обозначений |
| TYRES-DIAMETER | Диаметр диска из заводской маркировки перевести в мм, прибавить две боковины | Заводская маркировка находится в общем описании |
| TYRES-RADIUS-DELTA | Вычислить оба диаметра, половина разности | Следить за направлением сравнения |
| TYRES-PERCENT-ROTATION | Сравнить диаметры, поскольку множитель π сокращается | Округление только в конце |
| PAPER-F01 | Площади строк таблицы сопоставляются с половинными площадями форматов | Названия форматов убраны из таблицы, в разборе показаны произведения |
| PAPER-F02 | Число переходов между форматами даёт степень двойки | Возможны естественные повторы ответа |
| PAPER-F03 | Длина указана в условии, округление до заданной кратности | Не требуется читать рисунок |
| PAPER-F04 | Деление сторон и округление до десятых | Разные размеры часто дают одинаковый ответ |
| PAPER-F06 | Диагональ по Пифагору, затем деление на меньшую сторону | Фиксированный источник |
| PAPER-F07 | Размер шрифта умножить на отношение длинных сторон | Округление до целого пункта |
| STOVE-F01-CAPACITY-LIMITS | Сопоставить заданные границы диапазонов со строками | Выбрать верную границу, а не середину диапазона |
| STOVE-F02-ATTRIBUTE-MATCH | Найти массу или цену в нужной колонке | Запись последовательности сохраняет порядок |
| STOVE-F03-VOLUME | Произведение трёх размеров | Размеры двери не нужны |
| STOVE-F04-FLOOR-AREA | Произведение горизонтальных размеров | Высота не входит в расчёт |
| STOVE-F05-WALL-AREA-NET | Площадь четырёх стен минус дверь после перевода единиц | Проверить перевод см² в м² |
| STOVE-F06-PURCHASE-EXTRA-COSTS | Цена №3 плюс монтаж и доставка | Данные каталога и текста согласованы oracle |
| STOVE-F07-FIT-WOOD-DELIVERY | Объём, единственный подходящий дровяной вариант, цена с доставкой | Границы включены |
| STOVE-F08-COST-COMPARISON | Сравнить две цены с учётом указанного монтажа | В условии заранее названо направление, спрашивается разность |
| STOVE-F09-DIRECT-DISCOUNT | Цена × оставшаяся доля | Цена каталога является входом |
| STOVE-F10-REVERSE-DISCOUNT | Цена после скидки делится на оставшуюся долю | В V2 исходная цена отсутствует в каталоге и условии |
| STOVE-F11-CONDITIONAL-TWO-DISCOUNTS | Проверка порога, раздельное уменьшение двух сумм | Строгое неравенство |
| STOVE-F12-ARCH-RADIUS | Половина ширины и высота образуют катеты | Радиус убран с PNG |
| TARIFF-F01-MONTHS-MINUTES | Точные значения минут на верхнем графике | Сохраняется порядок запрошенных месяцев |
| TARIFF-F04-MONTHLY-BILL | Расход нужного месяца, лимиты и доплаты | Не смешивать единицы двух графиков |
| TARIFF-F05-EXTREMUM | Сравнить все 12 точек минут | Повтор минимума не делает числовой ответ неоднозначным |
| TARIFF-F09-PERCENT-FEE | Разность делится на начальную плату | Небольшая естественная ёмкость |
| TARIFF-F12-HOME-ISP | Сравнить абонплату и доплату для заданного расхода | Таблица выдаётся у вопроса |
| GARDEN-01-IDENTIFY | Найти четыре объекта по ориентирам и сетке | Готовая расшифровка отсутствует |
| GARDEN-02-TILES-PACKS | Из размеров четырёх полос и площадки получить площадь, округлить число пачек вверх | Сетка 2 м, ширина полос 1 м |
| GARDEN-04-PERIMETER-POLYGON | Подсчитать внешние стороны клеток | Геометрия фиксирована |
| GARDEN-07-PERCENT-BUILDINGS | Сложить указанные площади, разделить на площадь участка | Геометрия и числовой ответ фиксированы |
| GARDEN-09-HEAT-BREAKEVEN | Разность вложений делится на часовую экономию | Суммы приведены к правдоподобному диапазону |
| FLAT-01-ROOM-MATCH | Проёмы, вход, положение лоджии, площадь гостиной | Маркировка варьируется, топология фиксирована |
| FLAT-02-PARQUET-PACK | Уложить доски вдоль сторон без распила и округлить пачки | Размер гостиной фиксирован |
| FLAT-02-TILE-PACK | Число клеток санузла равно числу плиток | Меняется вместимость упаковки |
| FLAT-03-RECT-AREA | Число клеток × 0,16 м² | Естественно фиксированный вопрос |
| FLAT-04-RECT-PERCENT | Разность делится на площадь кладовой | Операнды уже в условии |
| FLAT-05-WASHER-MIN | Отфильтровать машины, сравнить полные цены | Разбор показывает цену каждой подходящей модели и базу процента доставки |
| FLAT-05-INTERNET-MIN | Для каждого плана вычислить абонплату и доплату | Небольшая таблица фиксирована, расход меняется |
