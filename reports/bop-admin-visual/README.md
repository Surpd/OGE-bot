# Визуальная приёмка bop Admin

[Галерея HTML](index.html)

Галерея включает 35 экранов и состояний. Сводки, подписи и клавиатуры получены из
тех же функций, которые вызывает бот. Цифры, даты и идентификаторы в превью
синтетические, включая имена и ники. Галерея показывает PNG, фактическую видимую
подпись и клавиатуру вместе; доступен выбор ширины 360, 390 и 430 px.

В полноразмерных скриншотах также есть список учеников, типы, повторы ошибок,
состояние системы и инструменты. Для этих экранов видны разметка текста,
пагинация и выбранная сортировка. В галерее показаны пустые отчёты, тайм-аут,
недоступное подключение и устаревшая карточка ученика. Отдельно показаны
«Подробнее», сегодняшняя активность без занятий, отсутствующий ник и длинное имя.

По умолчанию под PNG нет второго полного отчёта. Здесь остаются только значимые
предупреждения; числовые расшифровки открываются отдельной кнопкой. Список учеников
содержит один набор кнопок с Telegram-ником или именем, без повторяющегося списка UUID.
Тестовый транспорт проверяет переключение «Подробнее»/«Кратко» с сохранением
ученика, периода и страницы, а также возврат к родительскому списку.

Кнопки отрисованы отдельно от PNG, их минимальный размер в галерее — 44×44 px.
Текущие PNG проверены локально, включая длинное имя и пустые состояния.
Каталог `screenshots/` содержит **предыдущую версию до сокращения подписей**
из PR #123; это архив, а не подтверждение нового интерфейса. Переснять его
в текущем окружении не удалось: отсутствует бинарник Chromium, загрузка браузера
недоступна. Актуальными примерами служат `index.html`, `images/` и `payloads/`.
Открытие фото и текста, возврат, старая кнопка и явный отказ загрузки фото
проверены через aiogram с тестовым Telegram-транспортом.

После установки зависимостей репозитория команда
`python scripts/bop_admin_preview.py` обновляет HTML, PNG и JSON сообщений.
Параметр `--chromium /path/to/chromium` дополнительно обновляет три мобильных
скриншота. Локальную галерею можно открыть из сохранённого каталога целиком.
