# Приёмка тренировок bop Math

Примеры получены через реальный диспетчер aiogram с изолированной схемой PostgreSQL и синтетическим учеником. JSON содержит последовательность запросов Bot API, включая клавиатуры, Rich HTML и ссылки на отправленные PNG. Запросы перехвачены офлайн-транспортом. Снимки галереи сделаны в Chromium.

Формулы Rich Messages на снимках показаны в исходном LaTeX, который Telegram получает в payload.

## Аудит математических вариантов

- [Аудит 40 публичных семейств](audit.csv).
- [Методика и границы пространства вариантов](variant-identity.md).
- [Независимые примеры площади пола](floor-area.json).

Сценарий галереи проверяет, что пять задач на площадь пола имеют разные математические сигнатуры, продолжение сохраняет тип, а осознанный повтор PAPER-F07 увеличивает число верных решений с двух до трёх при прежних двух самостоятельных решениях новых вариантов.

В «Первой части целиком» диспетчер проверяет один общий снимок для №1–5, выдачу №6–19 по порядку и переход к следующему циклу. Сохранённая очередь из прежней версии используется при возобновлении.

Для повторного запуска нужны шрифты DejaVu и одноразовая локальная PostgreSQL. Задай `DATABASE_URL` и запусти `python scripts/live_training_acceptance.py` из корня репозитория. Скрипт создаёт и удаляет собственную тестовую схему.
