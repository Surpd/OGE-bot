Синтетический ученик решил восемь задач №6, семь из них со второй попытки. Фильтр ошибок показывает все семь. Проверены открытие записи со второй страницы, просмотр разбора и возврат на ту же страницу с обоими фильтрами. Из детализации №6 доступны результаты по типам, каталог и запуск тренировки.

## Смешанные тренировки

[Все 100 пятёрок и частоты по номерам и семействам](mixed-100-trainings.json) · [Запросы Bot API при ошибке генерации, повторной выдаче и завершении пятёрки](mixed-bot-api.json)

В симуляции на PostgreSQL использованы рабочий селектор, публичный реестр и синтетические снимки задач. В 500 выдачах каждый номер встретился 26–27 раз, охвачено 206 семейств. Во всех пятистах позициях проверены границы циклов и уникальность номеров внутри пятёрки. Отдельный прогон с генераторами записал фактические запросы Bot API через локальный транспорт.

| Тренировка | Номера в порядке выдачи |
| --- | --- |
| 1 | 15, 13, 3, 16, 18 |
| 2 | 12, 19, 2, 5, 9 |
| 3 | 8, 7, 17, 1, 6 |
| 4 | 11, 4, 10, 14, 19 |

Первые 19 позиций образуют полный цикл. Двадцатая открывает следующий цикл. В первой тренировке репозиторий и сессия были открыты заново перед третьей позицией. Отдельные PostgreSQL-тесты проверяют прерывание, повторное открытие, явное «Похожее», пропуск и изоляцию учеников.

## Воспроизведение

В тестовой среде проекта с локальной PostgreSQL задайте `DATABASE_URL` и `PYTHONPATH=.`. Для записи экранов прогресса включите `OGE_ADAPTIVE_ENABLED=true` и `OGE_PART2_ENABLED=true`.

- `python scripts/navigation_progress_acceptance.py` — журнал, аналитика, письменные работы и запуск практики.
- `python scripts/story_navigation_acceptance.py` — выбор сюжетов и продолжение практики.
- `REPORT_MIXED_ROTATION=1 pytest tests/test_mixed_rotation_postgres.py` — распределение и фактические запросы смешанной тренировки.
