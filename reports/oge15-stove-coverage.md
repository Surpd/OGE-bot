## Отказанные источники и границы

- F13 (`392860`, `392836`) не включён: подтверждённые параметры сами по себе не
  подтверждают отдельную целевую постановку про годовые расходы.
- F14 не включён: источник [408261](https://math-oge.sdamgia.ru/problem?id=408261)
  помечен в исследовании как `conflicted`; геометрию его рисунка нельзя переносить
  на F12.
- F15 не включён: для [408240](https://math-oge.sdamgia.ru/problem?id=408240)
  ключ `2` не соответствует сумме `15000 + 6500 + 1000 = 22500`. Источник
  используется только как отрицательный regression vector.
- Все 12 семейств остаются `enabled_candidate` с `enabled=False` в runtime
  registry до отдельного решения о публикации. Ветки генератора и report не
  включают их для учеников.
- Каждый seed формирует один каталог, одно помещение и одну геометрию арки;
  вопросы №1–5 используют тот же snapshot. Изображения таблицы и дуги строятся
  собственным SVG/PNG renderer и восстанавливаются из snapshot по SHA-256.

## Автоматическая проверка разнообразия

Прогон `python scripts/oge15_stove_quality_report.py --samples 250` выполнен на
текущей версии генератора: каждое семейство прошло 250/250 независимых oracle
проверок и дало 250 разных видимых fingerprints; полная пятёрка прошла 250/250
совместимых наборов и дала 250 разных fingerprints. Отдельные количества разных
ответов и источников по семействам находятся в `reports/oge15-stove-quality.json`.
PNG/SVG пересобираются из snapshot; регрессионный тест проверяет повторное
восстановление и SHA-256 для всех четырёх assets.
