[Построчный указатель семейств и прототипов](sources.md). Все страницы с суффиксами -1, -2 и далее находятся в этой папке. Для №6, 8–10, 12, 14 и 19 отдельной обязательной схемы задачи нет. Формула в сообщении и его растровая резервная копия зависят от транспорта Telegram. Сопоставления по семействам доступны в [реестрах источников](../../../atlas). Демоверсии ФИПИ подтверждают показанные в них типы. Для остальных использованы каталожные карточки и атлас проекта.

Для воспроизведения обычной выдачи запустите из корня:

```sh
PYTHONPATH=. uv run python scripts/oge_graphics_contact_sheets.py
PYTHONPATH=. uv run python scripts/oge15_graphics_preview.py /tmp/oge-practical
```

Визуальная проверка выборочная. Контактные листы охватывают разные варианты каждого публичного графического семейства, а не все допустимые seed. Физический клиент Telegram и его серверное сжатие здесь не проверялись. У №7 подписи по-прежнему растровые в каноническом PNG. Его изменение потребует версионирования и проверки старых изображений. №13 сохраняет исходные векторные варианты и интервалы. Обновлён только производный PNG. Для №1–5 исходные ресурсы восстанавливаются по сохранённым хешам независимо от мобильного оформления.
