# Прогресс bop Math

[Галерея](index.html) содержит 13 переходов с PNG, фактическими кнопками и отдельным JSON для каждого запроса Bot API. Для примеров использованы синтетические результаты в изолированной PostgreSQL 17 и снимки штатных генераторов. Карточки и запросы получены через действующий Telegram-диспетчер со стендовой доставкой.

Снимки браузерной галереи с PNG и кнопками сделаны в [360 px](screenshots/360.png), [390 px](screenshots/390.png) и [430 px](screenshots/430.png). Отдельные снимки [заполненного прогресса №13](screenshots/number-dense-390.png) и [его журнала](screenshots/journal-long-390.png) также доступны в масштабе 390 px.

В контрольной области 500 × 440 px фото журнала вписалось в [489 × 440 px](screenshots/desktop-500x440.png), фото прогресса №6 — в [450 × 440 px](screenshots/desktop-number-500x440.png). Это геометрия стендового просмотра. В галерее размеры видны под соответствующими карточками вместе с исходными PNG.

Проверка диспетчера прошла с журналом всех заданий и журналом ошибок, фильтром по номеру, второй страницей, записью и её решением, возвращением на те же фильтр и страницу и обновлением исходной сводки. Второй тест принудительно отключает отрисовку карточки и проверяет текст с теми же четырьмя записями, затем проверяет старый размер страницы без разрешённого пользователя.

Генерация галереи выполняется из корня репозитория через `python -X utf8 scripts/progress_route_acceptance.py` с `DATABASE_URL` для локальной тестовой PostgreSQL. Адресные проверки находятся в `tests/test_progress_visual_route.py`.
