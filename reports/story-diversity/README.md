## Как читать результаты

Исходный замер взят из [аудита PR №115](../live-training-acceptance/audit.csv), коммит `fa217335060876e26cd40cf1ca6c172b92f01716`. В матрице `before` и `after` показывают число разных математических входов среди 100 seed (0–99) для каждого запрошенного семейства. Это подтверждённые нижние границы. `different_answers` считает численно различные ответы, `answer_strings` учитывает также предписанную точность записи. Поле `parameters` перечисляет входы для идентификации варианта.

Галерея показывает условие, общий контекст, материалы вопроса, подсказки, разбор и математический ключ. Все изображения открываются локально по относительным путям. Для просмотра скачайте каталог целиком и откройте `index.html`. Вторая галерея получена через диспетчер aiogram и тестовый транспорт Bot API, который сохраняет отправленные байты PNG. В ней есть первоначальная выдача и повторное открытие «Схема / данные» для четырёх изменённых сюжетов.

## Методические ограничения

- **Участок.** Одна узнаваемая схема сохраняет расположение ворот, построек, дорожек и теплицы. Размеры в метрах определяют план, мощение, площади и периметр. Для дома доступны все 11 периметров от 28 до 68 м с шагом 4 м. Разные контуры с одним числом граничных отрезков при том же масштабе считаются одним вариантом периметра. Доля построек округляется до целых процентов по условию. [Проверка геометрии](../oge15-garden-coverage.md)
- **Квартира.** Меняются размеры помещений, масштаб и экономические параметры. Модель сохраняет восемь помещений и проверенные связи. Меньшая лоджия даёт 16 пар «площадь в клетках, масштаб». Для сравнения санузла и кладовой доступны 23 пары существенных входов. В задачах на отделку эквивалентный масштаб учитывается один раз. [Покрытие квартир](../oge15-flat-coverage.md)
- **Бумага.** Форматы A0–A7 имеют стандартные размеры. Раскрой даёт 30 сочетаний исходного числа листов и числа делений, округление стороны — 13 математических входов. Для отношения меньшей стороны к большей есть 16 сочетаний размеров и точности, но всего два численных ответа. Это ограничивает пользу механического повторения. Обратное отношение относится к исследовательскому PAPER-F05. Для диагоналей использованы четыре формата с точным восстановлением размеров из соседнего формата, две опорные стороны и две точности. Шрифт даёт 34 сочетания размера 8–24 пт и направления перехода между A3 и A4. [Покрытие бумаги](../../specs/coverage/OGE15_PAPER_COVERAGE.md)
- **Тарифы.** Три исходные платы 300, 350 и 400 рублей сочетаются с 21 ставкой повышения. Получаются 63 пары цен и 21 значение процента. Для месячного счёта используется плата того же тарифа. [Покрытие тарифов](../../specs/OGE1_5_TARIFF_COVERAGE.md)
- **Печи и шины.** Сохранены действующие структуры. В матрице приведены результаты проверки по каждой из них. Число совпадающих ответов может быть выше числа совпадающих математических входов.

## Воспроизведение

Из корня репозитория с зависимостями из `uv.lock`:

```sh
uv run python -X utf8 -m scripts.story_diversity_acceptance
uv run python -X utf8 -m scripts.story_diversity_telegram
```

Для второй команды требуется `DATABASE_URL` изолированной локальной PostgreSQL. Она создаёт временную схему и проводит одного синтетического ученика через практику по каждому типу. Тесты также сверяют проверку ответов в персональной и смешанной тренировках и в повторе ошибки. Четыре [снимка базового коммита](../../tests/fixtures/story_diversity) проходят восстановление прежних ресурсов по SHA-256 и проверку ответов по сохранённым версиям политик.

Состав публичного каталога и критерий закрепления по трём новым самостоятельным решениям сохранены. В миграции 0035 уже записанные события ставятся в очередь пересчёта по исходным снимкам. Исчерпание подтверждается только для семейств с доказанным конечным набором.
