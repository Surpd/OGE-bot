## Контракты, oracle и графика

`app/math/oge16_circles.py`: `generate(family_id, seed, generator_version)`;
seed — целое 0…2^63−1, версия строго `oge16-circles-1`. Один конечный выбор,
без неограниченного rejection sampling. Ответы — Fraction до форматирования,
без округления иррациональных чисел. Immutable `CircleProblem` хранит JSON;
`to_snapshot()` возвращает независимую копию, `.png` — сохранённые байты.

Snapshot v1 содержит problem_id/семейство/seed/версию, параметры, весь текст,
подсказку, полный разбор, fingerprint математических входов, ответ/политику,
provenance `generated_analogue`, CircleGeometry, layout, PNG base64/SHA256,
версию рендера `oge16-pillow-1`. `attempt_index` и метаданные очереди отделены
от математической идентичности. `from_snapshot` проверяет версию, seed,
математическую идентичность и **сохранённые** пиксели, не вызывает PNG renderer.
Неизвестные версии и повреждения отклоняются, без скрытой регенерации.

Независимый `oge16_oracle.py` не импортирует генератор. Полный разбор видимого
условия фиксирует числа, цель, вершины и единицы. Exact solve сверяется с
координатами: принадлежность окружности, направления дуг, диаметральность,
перпендикулярность, касание, середина хорды, равные стороны/прямые углы и
расстояния до всех сторон квадрата, выпуклый несамопересекающийся обход.
Каждый шаг решения и подсказка проверяются отдельно от ответа.

Pillow renderer разделён с моделью. Layout использует одну шкалу для обеих
осей, резервирует поля, размещает буквы без пересечений с линиями/окружностью
и друг с другом. Все числовые данные находятся в полном условии; рисунок
не заставляет считывать длины по масштабу. На источниках также нет обязательных
числовых меток на схемах. Дуги/маркеры прямых углов не добавляют готовый ответ.
`oge16_raster_oracle.py` проверяет PNG/SHA, affine transform, наличие всех
геометрических пикселей, точные глифы букв, отсутствие посторонних линий,
обрезки и столкновений, сохранность при 360/390/430 px. Это независимая
проверка перехода модель→пиксели, но **не** второй независимый геометрический
решатель: математическое доказательство даёт координатный oracle.

`app/bot/oge16_adapter.py` — не зарегистрированная фабрика существующего
`NumericTraining`. Scheduler закрыт по умолчанию; явный override семейств
предназначен для тестов. Бюджет ≤12 кандидатов на семейство, остановка после
первого пригодного, исчерпание выбранного типа возвращает [], без скрытого
fallback. Для будущей интеграции нужны регистрация, доставка сохранённого PNG,
проверка snapshot, persistence и общие UX/PG тесты — **в отдельном PR**.
Сам общий NumericTraining этого PR не меняется.

## Проверки и ограничения

Команды:

```text
python -m pytest -q tests/test_oge16_circles.py
python scripts/oge16_quality_report.py --samples 300
ruff check .
mypy app
```

QA JSON: `reports/oge16-quality.json`. 300 полных текст/geometry/PNG проверок
на семейство; 1200 математических вариантов для приёмки разнообразия.
Тесты: исходные числовые контроли, seed/version replay и неизвестные версии,
изменения текста/единиц/цели/политики/шагов, большая дуга вместо малой,
секущая вместо касательной, хорда вместо диаметра, неверное касание квадрата,
самопересечение, неверная середина хорды, PNG с обновлённым SHA, пустое и
сдвинутое изображение, перепутанные/обрезанные буквы, очередь и исчерпание.
`reports/oge16-preview.png` — собственные аналоги на 360 px для визуального review.

Применены LL-01/14/17 (видимое условие/цель/шаги и честный provenance),
LL-22 (один выбранный PNG, сохранённый рисунок при восстановлении),
LL-23 (топология исходной геометрии проверяется отдельно от ответа).
