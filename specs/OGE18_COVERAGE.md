# №18: закрытая реализация M01/M02

Основа: `origin/main` e7a2f99; исследовательская ветка
`docs/geometry-15-19-codex-handoff`, реестр `GEOMETRY_RESEARCH_GATES_15_19.md`.
Публичный `ENABLED_FAMILIES=()` в `oge18.py` и scheduler. №18 скрыт в меню;
закрытые тесты явно включают семьи. Другие семейства №18 и №15–17/19 не реализованы.

| Семейство | Проверенный каталогный образец | Структура | QA |

| OGE18-M02 | [348638](https://math-oge.sdamgia.ru/problem?id=348638) | основания 9 и 3 → m=6, без подписей и средней линии | 300 кандидатов, 204 уникальных |

Проверка оригинальных рисунков относится к исследовательскому handoff от 14.11.2026:
[треугольник, лист 1/6](https://math-oge.sdamgia.ru/pdf/035b7415a9ab2fc0cdd2de50a8ed201e.pdf),
[трапеция, лист 5/5](https://math-oge.sdamgia.ru/pdf/aaef55676f047381cb69d6ae75078c3e.pdf).
Это не заявление о прямой верификации окончательного банка ФИПИ-2027.
Остальные ID хранятся в атласе как не перепроверенные индивидуально.
Чужие изображения и формулировки не копируются.

Модель и ограничения точно соответствуют заданному подмножеству: M01
b ∈ {4,6,8,10,12,14}, 1≤t<b, 3≤h≤11; M02 6≤L≤12, 2≤u≤L−2,
1≤s≤L−u−1, 3≤h≤8. Перенос начала в (2..3, 2..3) укладывается в фиксированную
сетку 20×17 клеток. Детерминированного повторного семплирования не требуется:
все параметры безопасны; attempt_index=0. Недопустимые данные отвергаются.
Полная ёмкость с исключением переносов и зеркал: M01 243, M02 552.
Fingerprint учитывает длины оснований, высоту и зеркально нормализованный сдвиг,
а также цель задачи. Число разных ответов существенно меньше числа фигур;
этот отчёт не доказывает разнообразие экзаменационных типов или полноту банка.

Версии: `oge18-grid-1`, `oge18-pillow-1`, policy `oge6.numeric-short` / `1`.
Snapshot самодостаточен, frozen-объект хранит JSON-строку, accessor возвращает копию.
Ограничения: 250 KB JSON, 150 KB PNG, seed 0≤seed<2^63, UUID5 identity.
Restore проверяет версии, точные координаты/ответ, текст, подсказки, разбор,
источник, fingerprint, SHA и конечные пиксели. Подмена меток, дополнительные линии,
исчезновение сетки и неверные рёбра отвергаются даже при пересчитанном SHA.
Генераторная формула сверяется с независимым Fraction-oracle из середин сторон,
параллельности, квадратов расстояний, выпуклости и shoelace.

PNG 720×640 строится в двойном разрешении; шаг одинаков по осям — 32 px.
Аудит проверяет PNG при 360/390/430/720 px и полное соответствие версии сцены.
[Контакт-лист M01, 360px](../reports/previews/oge18/OGE18-M01-360-contact.png),
[M02, 360px](../reports/previews/oge18/OGE18-M02-360-contact.png);
рядом находятся варианты 720px и два контрольных seed=0. Всего шесть PNG,
меньше 1 MB; сотни отдельных вариантов не сохраняются.
Контакт-листы 360px (20 разных фигур каждого семейства) просмотрены агентом:
буквы ABC относятся к правильным вершинам, клетки квадратные, лишних линий нет;
у трапеции подписей нет. Это визуальный осмотр локальных файлов, не мобильный
Telegram smoke и не новый независимый просмотр оригиналов каталога.

Интеграция использует общий numeric engine и presentation.send_photo, без нового
хранилища. SQL/memory методы следуют существующему per-task контракту №14;
одна идемпотентная миграция 0014 создаёт частичный индекс сессий task18.
По состоянию начала работы других открытых PR не было; 0014 свободен.
Снимки №1–14 не преобразуются. Прогресс и его тесты не изменялись.

Проверки: общий UX harness расширен №18; дополнительно проверяются media bytes,
resume без сброса попыток, повреждение snapshot, закрытый флаг, Rich/fallback,
PNG-настройка, неоднозначный timeout без второй отправки. PostgreSQL 17 тесты
проверяют восстановление новым repository, две попытки/duplicate, конкурентные
ответы/next/skip, stale prompt, паузу/restart и повторное применение миграции.
Общие webhook тесты остаются финальным регрессионным барьером.
Применимые уроки: LL-01/02/08/09 — текст, источник, novelty, policy;
LL-03/04 — реальные SQL/restore; LL-05/06/07/12/13/16/19 — общий UX harness;
LL-20/22/23/25 — runtime font, один кандидат, точная сцена, media transport.

Воспроизведение: `uv run python scripts/oge18_quality_report.py`;
`uv run pytest -q tests/test_oge18_math.py tests/test_task18_flow.py tests/test_oge18_postgres.py tests/test_training_ux_contract.py`.

полный PG gate выполняется в существующем CI. Живой Telegram, мобильные клиенты,
проверка окончательного ФИПИ-2027 и разрешение публичного включения остаются
release blockers. Merge/deploy в эту работу не входят.
