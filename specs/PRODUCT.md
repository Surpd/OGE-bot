# Функциональная спецификация — Telegram-бот v1

## Миссия
Ученик едет в метро, открывает Telegram и **за 1–2 нажатия** начинает решать краткие задания ОГЭ. Никаких обязательных «уроков по плану» и навязанных уведомлений. Бот может ненавязчиво предложить потренировать слабый тип после решения.

## Главное меню
- **⚡ 5 минут** — 5–7 коротких заданий; выбор по уровню и истории, пропуск без штрафа; результат по окончании.
- **🧮 По номеру** — 1–19, затем «Все типы» или конкретный подтверждённый подтип. Номера без проверенного контента показаны как «готовится», а не ведут в пустоту.
- **🔁 Мои ошибки** — новый экземпляр той же математической операции, а не повтор буквального текста.
- **🏆 Марафон** — 3 жизни, случайные задания из включённых типов, рекорд, явные правила потери жизни.
- **📊 Прогресс** — успешность с первой попытки, попытки после подсказки, типовые затруднения; никакой псевдоточности на 2 ответах.
- **📚 Как решать** — сохранённые эталонные решения и простые фиксированные подсказки.
- **▶ Продолжить** — если есть незавершённая сессия.

## Сценарий одной задачи
1. Бот отправляет текст/изображение (или 5-заданный общий сюжет) и кнопки `💡 Подсказка`, `⏭ Пропустить`, `🧾 Решение`, `🏠 Меню`.
2. Ученик отправляет число/номер/последовательность цифр. Ввод нормализуется **по типу ответа**, без бездумного `replace(',', '.')`.
3. При верном ответе — короткая обратная связь; отдельно считать «с первой попытки» и «с подсказкой»; кнопка `Следующая`.
4. При первой ошибке — **не раскрывать немедленно** ответ, позволить вторую попытку, предложить подсказку.
5. При второй ошибке — показать подготовленный точный разбор, предложить аналогичную задачу. Нельзя молча изменить исходную задачу.
6. При пропуске — сохранить факт, не считать как математически неверный ответ для оценки освоения, но учитывать в активности.
7. `/cancel`, `/start`, повторные callbacks, повторный webhook после рестарта — не теряют уже зафиксированные результаты.
8. Результат сохраняется до отправки или через надёжную идемпотентную операцию; retry не должен создавать дубли статистики.

## Правила конкретных номеров
- №1–5: **один** комплект, единая модель, общий рисунок/таблица, 5 связанных вопросов; «Показать схему снова» без перегенерации комплекта.
- №7 и №13: если задача содержит варианты, ответ ученика — номер варианта и проверяется уникальность выбора.
- №11: 2–4 графика показываются в одной картинке; ответ — последовательность цифр по требованиям данного задания.
- №15–18: условия и рисунки в сообщениях Telegram; если рендер нечитабелен на мобильном — задача выключена.
- №19: форма истинных утверждений задаётся версией экзамена и конкретного шаблона, не предполагать автоматически «выбрать все» или «ровно одно».

## Прогресс, повторы, режимы
- Прогресс по **навыкам и подтипам**, а не только по № ОГЭ. Без навязывания планов; рекомендации только в главном меню или после сессии.
- В рамках сессии запрещены точные дубликаты. Для подтипов по возможности ограничивать эквивалентные перестановки и «те же числа в другом сюжете».
- Выданное условие — immutable snapshot. При обновлении кода прежние задачи и ответы не меняются.
- Без самостоятельных массовых исходящих уведомлений несовершеннолетним; подписка на напоминания позднее, только opt-in.

## Роли
- Обычный ученик: без регистрации, достаточно Telegram ID и минимального профиля.
- Учитель: назначение практик/аналитика **после** первой публичной версии; отдельный доступ, не через админ-кнопку у всех.

## Что НЕ входит в первую версию
Mini App, №20–25, автогенерация изображений через ИИ в момент ответа, развёрнутая переписка с Groq, автоматическое выставление школьных оценок, сложные рейтинги и платная инфраструктура.
