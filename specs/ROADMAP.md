# Roadmap — этапы, результаты и критерии окончания

| Фаза | Результат | Минимальная приёмка |
|---|---|---|
| **0. Исследование + пакет** | Атлас, решение об архитектуре, список формулировок | Все №1–19 зарегистрированы, статусы и пробелы видны |
| **1. Foundation** | Новый GitHub repo, Python app, Telegram `/start`, Supabase, Northflank Sandbox | Tests/CI зелёные, webhook работает после рестарта, затраты в лимите |
| **2. Golden generator** | Один образцовый механизм №6 на точных дробях/AST | ≥200 уникальных корректных, ≥10k seeds, независимый oracle, все баги legacy регрессионными тестами |
| **3. MVP** | №6, №9, №10, №14, меню, подсказки, повторные попытки, прогресс | Несколько интеграционных пользовательских сценариев, нет неверных ответов в тестах |
| **4. Мотивация** | 5 минут, марафон, ошибки, ненавязчивые советы | Без навязанных уведомлений; восстановление сессии после рестарта |
| **5. Алгебра / визуализация** | №7–8, №11–13 | Не выдаются неподтверждённые типы, SVG/PNG соответствует модели |
| **6. Геометрия** | №15–19 | Автоматические геометрические оракулы, карантин непроверяемых утверждений |
| **7. Сюжеты** | №1–5: хотя бы один связный тип с общей графикой, затем остальные | Полный комплект согласован из одного seed; общая схема при всех пяти вопросах |
| **8. Пилот** | Ученики в Telegram, мониторинг, исправления | Контроль дублей, нагрузочные тесты, быстрый откат; нет блокирующих дефектов |
| **Later** | Учитель, Groq-пояснения, Mini App, №20–25 | Отдельные ТЗ, никаких действий в рамках первого релиза |

## Статус фазы 1 — 31.10.2026

- Локально созданы FastAPI/aiogram приложение, меню-заглушки, миграция, тесты, Dockerfile и CI workflow.
- GitHub connector доступен для чтения/работы с файлами, но локальная авторизация GitHub UI отсутствует,
  а CLI `gh` не установлен; создание нового repo заблокировано до входа владельца в GitHub.
- Supabase доступен в одной организации; виден один проект. Новая Free project квота по документации
  допускает до двух активных проектов, но Supabase tool требует выбора организации владельцем.
- Northflank Sandbox в прайсинге объявлен бесплатным ($20/мес., always-on), однако официальные billing
  docs одновременно требуют платёжный метод и описывают автоматические счета. Ресурсы не создавались.
- Ещё не выполнены: создание отдельного Supabase проекта, Northflank project/service,
  GitHub Actions run и Telegram smoke test. Не считать фазу принятой до этих проверок.
- Платформенные ограничения и доступы записываются в `specs/DECISIONS.md` по мере проверки.

**Релизная политика:** фазы 1–3 делить на маленькие pull requests. Нельзя называть всё «готово» только потому, что бот показывает приветствие. Проверенные семейства выводятся по отдельности, покрытие — с известными пробелами.
