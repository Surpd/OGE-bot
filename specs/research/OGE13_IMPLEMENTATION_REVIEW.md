# ОГЭ №13 — сверка источников и решение по пилоту

**Проверено:** 01.11.2026. **Источник пакета:** `OGE13_GENERATOR_RESEARCH_V4_BRANCHES.zip`.

## Статус доказательств

Пакет содержит 18 отдельных карточек Решу ОГЭ с URL и математическими сводками. Карточки открыты адресно; текст условий и опубликованные разборы сопоставлены с `oge13_source_cases.json` и независимым пересчётом. Графические страницы проверены в браузере по их оригинальным SVG. Портальные подписи источников фиксируются как атрибуция портала, а не как независимая сверка с полным КИМ ФИПИ.

CSV `OGE13_CATALOG_144.csv` и `OGE13_EXTRA_7.csv` являются навигационным снимком. Их 151 строка не считается индивидуально проверенными заданиями или доказательством охвата банка.

### Расхождение в переданном пакете

В `oge13_source_cases.json` для карточки №107 записан номер ответа 2 со статусом «не проверен по SVG». На открытой карточке портал указывает ответ 1; оригинальный SVG также показывает вариант 1 как `x≤7/2`. Для геометрии семейства используется множество решений, а не цифра из пакета. Это расхождение должно оставаться отдельной регрессией, чтобы перестановка вариантов или ошибочное поле ответа не меняли математическую семантику.

## Оставленные вне пилота

- **OGE13-Q05, карточка [185](https://math-oge.sdamgia.ru/problem?id=185):** оригинальный рисунок отдельно осмотрен; он показывает открытый интервал `(-2;2)`, которому соответствует только `x²−4<0` (вариант 4). Это обратная постановка «рисунок → неравенство» и требует отдельного генератора и тестов для четырёх кандидатных неравенств. Её нет среди пилотных типов; генератор не реализуется в этом этапе.
- **OGE13-Q06, карточка [356077](https://math-oge.sdamgia.ru/problem?id=356077):** оригинал показывает закрытый отрезок `[−8;8]` для `x²≤64`, но карточка связывает его с атрибуцией «ОГЭ 09.06.2023, Санкт-Петербург, вариант 2409», а пакет отмечает противоречие атрибуции. Семейство выключено до отдельной проверки первичного КИМ/источника.
- **OGE13-S04, карточка [322330](https://math-oge.sdamgia.ru/problem?id=322330):** видимая система приводит к `x>4` и `x<3`, то есть к пустому множеству. Приложенный разбор решает другую систему `5x+13≤0`, `x+5≥1` (вариант из карточки №311672); страница отдельно ссылается на прототип. Поэтому разбор не подтверждает ответ для №322330. Семейство исключено из пилота до независимого аудита варианта и его происхождения.

## Решение по публикации

Пилотное покрытие ограничено девятью перечисленными семействами. Числовые параметры разрешено менять внутри этих подтверждённых форм; новые типы, сюжеты и постановки не добавляются. Сгенерированные условия обозначаются тренировочными аналогами, а не оригинальными заданиями банка.

Все новые семейства остаются выключенными для выдачи ученикам по умолчанию. Исследовательская проверка первоисточников сама по себе не заменяет математический QA, быстрый и основной прогоны, визуальный аудит собственных PNG на мобильном размере, PostgreSQL 17 CI и отдельное решение о включении.

## Follow-up ревью PR #8 — генератор 0.2.0

- Source regressions фиксируют отдельно подтверждённые системы: S01 `x+2,6≤0; x+5≥1` (ID 340580), S02 `x+3≥−2; x+1,1≥0` (ID 348461), S03 `x>3; 4−x>0` (ID 333109). Их интервальные решения и граничные точки проверяются независимым тестовым интерпретатором.
- S01–S03 генерируют коэффициенты и переносимые константы внутри этих алгебраических форм. Для S03 сохраняется отрицательный коэффициент; тесты проверяют разворот знака и десятичную точность.
- Ошибка с отвлекающим интервалом `(1;0,5)` покрыта регрессией для правильного `(0;0,5)`. Все варианты должны быть каноническими, корректными и попарно математически различными.
- PNG проверяется декодированием пикселей: членство на прямой и включение каждого конечного конца сопоставляются с сохранёнными множествами интервалов. Telegram рендерит snapshot-варианты; несовместимая версия явно отклоняется, автоматически заменяющее задание не создаётся.
- Ветка остаётся с пустым `ENABLED_FAMILIES`; номер №13 скрыт из меню. В отчёт добавлены пять конкретных сгенерированных примеров с вариантами/решениями и текущие показатели разнообразия.
