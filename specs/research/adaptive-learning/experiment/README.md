# Изолированный эксперимент bop Math

Python 3.11 или новее. Основной симулятор использует только стандартную библиотеку. Все данные вымышлены. Команды выполняются из каталога `experiment` в PowerShell, bash или другом терминале.

```console
python -m unittest discover -s . -p "test*.py" -v
python simulate.py --workers 4 --seeds 100
python summarize.py
python uncertainty.py
python archive_runs.py --remove-csv
```

Сводные таблицы и SVG создаются в `results`. Последняя команда сверяет распакованные байты с исходным CSV и оставляет `runs.csv.gz`. Чтобы заново построить отчёты из архивных данных без симуляции:

```console
python -c "import gzip,pathlib; p=pathlib.Path('results/runs.csv'); p.write_bytes(gzip.decompress(p.with_suffix('.csv.gz').read_bytes()))"
python summarize.py
python uncertainty.py
```

## Устройство

- `model.py` принимает только наблюдаемое событие. Словарь событий сохраняет историю входа в проекцию. Повтор идентификатора ничего не меняет. Одинаковая задача, в том числе после помощи или показа ответа, больше не даёт независимого свидетельства. Вход должен приходить в каноническом порядке. Навык и семейство заданы целыми идентификаторами.
- `simulate.py` хранит скрытые состояния и моделирует действия ученика. Вызов `queue` получает только день и лимит, `apply` получает только результат. Контрольные задачи не меняют состояние ученика или алгоритма. Один запуск симулирует 90 дней, дни 7 и 30 — вложенные срезы той же траектории.
- `summarize.py` агрегирует счётчики, чтобы не усреднять проценты без учёта знаменателей. Для каждой доли опубликован знаменатель. Пустое значение означает отсутствие наблюдений. Колонка `*_n` для средней задержки означает число обнаружений или подтверждений.
- `uncertainty.py` сравнивает отношения сумм в 2 000 парных бутстрэп-выборках из 100 блоков seed. Каждый блок содержит все десять профилей. Интервалы описывают вариацию симулятора при фиксированных допущениях.
- `results/runs.csv.gz` — 36 000 строк счётчиков. `summary.csv` — профили и общие результаты; `paired.csv` — средние попарные различия против rules по числу событий и другим показателям; `ratio_intervals.csv` — разности долей, п.п. `false-closures.svg` — сравнение всех профилей.

## Генератор мира

Восемь навыков, у каждого три семейства с поправкой к вероятности −0,09, 0 или +0,09 и по 120 вариантов. Стартовая сила навыка равна центру профиля с независимым равномерным разбросом ±0,24 и ограничена [0,08; 0,98]. Ежедневное забывание сдвигает силу к 0,12, прирост от задания пропорционален запасу до единицы. Относительная эффективность в симуляторе составляет 0,75 для самостоятельного успеха, 0,42 для ошибки, 1 для подсказки, 0,55 для разбора и 0 для пропуска. Знакомая задача умножает прирост на 0,27. Это исследовательские допущения, в частности помощь в этом мире способствует обучению. Для семи навыков вероятность случайно ответить верно после неуспеха равна 0,025, для восьмого — 0,25. Ответ может быть извлечён из памяти для знакомой задачи. Нет свободного текста или реальных решений ОГЭ.

| Профиль | Начальная сила | Посещение | Описка | Помощь | Вспоминает знакомое | Выход после первого слота |
|---|---:|---:|---:|---:|---:|---:|
| A сильный регулярный | .91 | .88 | .03 | .04 | .40 | .02 |
| B средний регулярный | .63 | .78 | .05 | .20 | .40 | .04 |
| C с трудностями | .31 | .72 | .08 | .55 | .40 | .13 |
| D нерегулярный | .60 | .73 | .06 | .18 | .40 | .05 |
| E часто берёт помощь | .55 | .78 | .05 | .69 | .50 | .06 |
| F невнимательный | .88 | .80 | .21 | .10 | .40 | .05 |
| G запоминает | .48 | .76 | .06 | .18 | .98 | .05 |
| H ищет награду | .48 | .84 | .08 | .26 | .80 | .05 |

У D 12 дней из каждого 21-дневного цикла недоступны. J прекращает входы сразу после 14-го дня. Для всех профилей история в момент старта пуста. G с вероятностью 0,78 выбирает последнее условие этого навыка, H с вероятностью 0,76. H в 72% слотов сам выбирает один и тот же навык и иногда имитирует неверный ответ. Для прочих профилей вероятность явного воспроизведения условия 0,08. Помощь зависит от потенциального успеха (ошибающиеся чаще просят помощь). При тренировке слабого места вероятность выхода из сессии дополнительно растёт на 0,08. Пропуски заданий сгенерированы с постоянной вероятностью 2,5%. Скука, добровольное возвращение и психологическая мотивация как результат награды здесь не моделируются.

## Проекции

Все алгоритмы учитывают только первую чистую попытку или первую ошибку по незнакомой задаче, различают семейства, требуют новую самостоятельную проверку не ранее чем через 7 дней после предварительного подтверждения. Помощь, знакомый snapshot и неизвестный статус записываются в историю. Ни одно такое событие не добавляет математических доказательств. Исторический факт награды постоянен. В модель поступают только доступные навыки. Зарегистрированный пул семейств и транзакционные ограничения Telegram проверяются отдельно в адаптере.

| Политика | Выход на первичную проверку после успеха | Вход в практику после ошибки |
|---|---|---|
| rules | ≥3 верных из последних 6, 2 последних верных, ≥2 семейства среди верных | ≥2 независимых ошибок из последних 3 |
| weighted | (1+положительная масса)/(2+положительная+отрицательная) ≥0,72; ежедневное затухание с постоянной 30 дней | тот же показатель <0,45 и ≥2 ошибок из последних 3 |
| bkt | двухсостоянийный фильтр с эвристическим забыванием, posterior ≥0,88 | posterior ≤0,45 и ≥2 ошибок из последних 3 |

Во всех вариантах перед квалификацией нужно ≥2 самостоятельных успехов по ≥2 семействам в пределах последних 6 независимых попыток за 45 дней. При единственном доступном семействе кандидат так и останется без подтверждения межсемейного переноса. В этом случае продукт может сообщить только о решениях конкретного типа. У BKT начальное p=0,35, дневное затухание в сторону 0,15 с постоянной 90 дней; P(верно|знает)=0,9, P(верно|не знает)=0,2, условное обучение после независимой попытки 0,1. Параметры не оценивались по ученикам. Взвешенный счёт учитывает и старые наблюдения с затуханием. Таймер после первичного свидетельства — 7 дней, затем 14 и максимум 30. После самостоятельной ошибки очередная проверка возможна через день, но никогда раньше семи дней после первоначальной квалификации. Две релевантные ошибки могут вернуть в практику. Дата сама по себе сохраняет состояние. Эти числа — условия эксперимента.

Очередь за один проход выбирает до двух просроченных проверок, до двух затруднений, один новый навык. Остаток добирается из непросроченных навыков, предпочтение отдаётся давно не предлагавшимся, затем редко предлагавшимся и меньшему стабильному ID. В сессии навык не повторяется, кроме явного переопределения самим учеником H. Если все навыки просрочены, возвращаются только две проверки. Для реального пятислотового UX оставшиеся слоты можно предоставить как отдельную практику с сохранением назначения каждого слота. Сейчас укороченная сессия входит в знаменатель завершения пяти задач, что способно занижать этот показатель.

## Метрики и границы

«Освоено» в скрытой модели означает силу ≥0,75, «слабое место» — силу <0,55; средняя зона не считается слабым местом. При каждом новом входе в confirmed ложность оценивается по скрытой силе **до** учебного эффекта текущей задачи. При каждом входе в practice проверяется истинное слабое место в этот момент. Полнота обнаружения — число разных навыков, хотя бы раз корректно помеченных в слабый момент, к числу хотя бы раз слабых навыков. Задержка для обнаруженного навыка отсчитывается от первого скрытого снижения ниже порога, может включать восстановление и рецидив. Невыявленные навыки в среднюю задержку не входят.

Независимый контроль на срезах моделирует по одной новой задаче для каждого из восьми навыков с надбавкой сложности 0,09, с описками и угадыванием. Для контроля применяется отдельный стресс на память v·(1−забывание)^7 и семь дней без занятий. Он отличается от обычного дневного затухания к 0,12. Ответы контрольных задач никогда не поступают движку. `delayed_probe_confirmed` учитывает только навыки, имеющие текущее состояние confirmed в день среза. `late_accuracy` измеряет успех на свежих проверках внутри фактической очереди, а `transfer_after_help` — первый следующий свежий самостоятельный ответ в том же навыке после помощи. Обе метрики подвержены отбору. Для не вернувшихся к самостоятельной задаче результат неизвестен.

Показаны отдельно накопленные награды, текущая скрытая сила и текущие проверочные ответы. Награды выдаются один раз на навык. Использован единый диапазон seed 0–99; в один день и слот случайные экзогенные числа одинаковы для всех политик. Различия вызваны состоянием алгоритмов, выбором следующего задания и ответом синтетического ученика. Сто прогонов дают 1 000 траекторий на политику и мир, поэтому можно оценить погрешность симуляции; по редким событиям в отдельных профилях знаменатели малы. Стоимость SQL и сети нельзя измерить этим движком в памяти.
