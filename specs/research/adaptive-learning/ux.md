# bop Math. Тренировки, прогресс и школьный пилот

## Что видит ученик сегодня

Проверено по исходному коду. На 25 ноября 2026 года в основной ветке главное меню даёт «Смешанная тренировка», «По номеру», «Мой прогресс», «Настройки» и условное «Продолжить». Каталог показывает по шесть позиций, включает №1–5 одним пунктом и добавляет №20–25 по флагу. У обычной задачи есть подсказка, разбор, пропуск и меню, после завершения — следующая задача и меню. Контракт предусматривает две допустимые попытки. Некорректный формат, выход в меню и возврат не создают ошибку. Старая документация перечисляет меньше входов, чем код. Источники — [меню](https://github.com/Surpd/OGE-bot/blob/98a6b9127878468199c0c12472c632da60d6cc2e/app/bot/menu.py), [обработчики](https://github.com/Surpd/OGE-bot/blob/98a6b9127878468199c0c12472c632da60d6cc2e/app/bot/router.py), [контракт](https://github.com/Surpd/OGE-bot/blob/98a6b9127878468199c0c12472c632da60d6cc2e/specs/TRAINING_UX_CONTRACT.md).

Вход появляется после первого содержательного результата в №1–19. Ветка разрешает подтвердить текущую успешность тремя свежими самостоятельными решениями подряд за одно занятие. Повтор исходника серию не увеличивает. Две ошибки в одной задаче могут открыть пробел. Интервалы ранее сняли сознательно. Ниже предлагаются изменения к этому кандидату. ## Навигация и пять задач

- **Главное меню.** «Продолжить» первой строкой при сохранённом контексте, затем «Тренировки», «Мой прогресс», «Настройки». Из прогресса рядом с рекомендацией можно сразу начать пятёрку либо продолжить выданную задачу.
- **Тренировки.** «Персональная тренировка», «По номеру», «Смешанная тренировка». Первый пункт без дополнительного экрана выдаёт задание. Доступ в первый день — из этого же пункта: пока нет истории, бот подбирает обзорную пятёрку и говорит об этом в заголовке первого задания. Так устраняется необходимость сначала догадаться пройти другой режим для разблокировки в #110. При выключенной персонализации остаётся обзор по доступным типам только по явному выбору. 
- **По номеру.** Выбор номера задаёт область тренировки. «Выбрать тип» сужает её внутри номера. Тематическая тренировка из карточки навыка использует этот же путь с уже выбранным фильтром. «Дроби» могут появляться в нескольких номерах только при проверенной разметке, а «№13» охватывает несколько умений.
- **Границы занятия.** Для новых коротких тренировок цель — пять задач. Свободная практика и действующий непрерывный Mix остаются доступными отдельным вторичным выбором. Домашняя работа и экзаменационный вариант живут по собственным правилам. Сохраняем «4 из 5» для короткой тренировки и «4 из 5 самостоятельно» для задания учителя там, где назначены именно пять правильных. Пропуск может закрыть позицию занятия, но не выполняет цель домашней работы.
- **«Ещё похожую».** После терминального исхода на позиции 1–4 можно выбрать «Дальше» либо «Ещё похожую». Новая аналогичная задача занимает следующий свободный слот в той же пятёрке. План не удлиняется, предыдущий результат сохраняется. Для последней позиции сначала показать итог, затем предложить отдельную новую тренировку с аналогом на первой позиции. В истории ошибки два однозначных действия — «Та же задача» и «Новая похожая». Первое создаёт новую попытку по исходному snapshot. Второе проверяет новизну видимой математики, включая ранее показанные в других режимах варианты. Если вариантов нет, кнопка исчезает либо объясняет «Свежие варианты этой темы закончились. Можно перейти дальше». Пропуск или две попытки на одном варианте дают максимум одно наблюдение о затруднении.
- **После первой ошибки в активной задаче** ученик сохраняет вторую попытку. Вложенное в «Пропустить» действие «Перейти к похожей» завершает прежнюю позицию пропуском и объясняет это до перехода. После второй ошибки или раскрытия разбора «Ещё похожую» показываем сразу. Для ученика после двух трудных задач подряд система может подобрать знакомое представление или короткое диагностическое задание. Никакого обязательного бесконечного повторения.
- **Сюжет №1–5.** При выборе всей пятёрки остаются один сюжет, общая схема, последовательные позиции. Для адаптивного одиночного вопроса показываем все относящиеся к нему данные и делаем схему доступной повторно. Не заимствуем иллюстрацию от другого комплекта. Если ученик уже придумал один промежуточный ответ для общего сюжета, соседние вопросы того же комплекта нельзя использовать как независимые доказательства переноса. Исключённые семейства, закрытые сюжеты и неподтверждённые типы фильтруются до выдачи и повторно проверяются при возобновлении выдачи новых слотов.
- **Письменные, экзамен и назначения.** Для №20–25 по флагу показываем доступную статистику, балл по критерию и факт проверки. Ошибка API, нечитаемое фото, изменённая работа и ожидание проверки имеют собственные статусы. Текст ответа или частичный балл сами по себе не называют причину ошибки. Не добавляем письменную работу в короткую пятёрку первой части. При экзаменационной попытке скрыты помощь, перенос к похожей и рекомендации до сдачи. Назначение учителя сохраняет исходные задания, правила зачёта и срок, персональный план не заменяет позицию домашней работы.

## Экранный маршрут

Примеры ниже используют обращение на «ты». Числа, дата и темы иллюстрируют синтетическую историю. В продукте их подставляют из записанных событий. В квадратных скобках приведены видимые подписи кнопок, знак · между кнопками обозначает один ряд.

| Ситуация | Что увидит ученик | Кнопки и последствия |
|---|---|---|
| 1. Первый запуск | «Персональная тренировка · 1 из 5. Начнём с разных тем. Вычисли ¾ − ½. Ответ запиши числом». | [Подсказка] · [Разбор], [Пропустить] · [В меню]. Допустимый ответ 0,25. Каждое задание отправляется обычным транспортом семейства. |
| 2. Первая ошибка | «Пока неверно. Осталась ещё одна попытка». | [Подсказка] · [Разбор], [Пропустить] · [В меню]. Числовой ответ в чат. Тему пока не обозначаем как слабую. |
| 3. Повторная трудность на ином варианте | «В двух разных задачах на вычитание дробей возникла ошибка. В следующей тренировке попробуем ещё один пример». | В карточке прогресса [Потренироваться] · [Посмотреть задачи]. Пока причина не проверена, не приписываем ученику ошибку со знаменателем. |
| 4. Подсказка | «Половина — это две четверти. Сколько четвертей останется?» | Ввод ответа открыт, число оставшихся попыток сохраняется. При успехе «Верно, с подсказкой». Если полный разбор раскрыт, задача терминальна. |
| 5. Самостоятельный аналог | «Верно с первой попытки. Это новая задача на вычитание дробей. Самостоятельно решено 2 из 3». | [Дальше] · [Ещё похожую], [В меню]. Прогресс в примере относится к конкретной серии. |
| 6. Получается сейчас | «Три новых примера подряд решены самостоятельно. Сейчас вычитание дробей получается. Через несколько дней попадётся ещё один пример». | [Дальше] · [Ещё похожую]. Очередное занятие доступно сразу. |
| 7. Наступил срок проверки | При открытии «Тренировки» — «Сегодня в подборке есть вычитание дробей. Последняя самостоятельная серия была неделю назад». | [Персональная тренировка] · [По номеру]. Нет долга, пропущенного дня или автоматического уведомления. |
| 8. Отсроченное подтверждение | «Ты решил новую задачу без подсказки спустя неделю. В карточке “Вычитание дробей” появилась отметка о повторении». | [Дальше] · [Мой прогресс]. Дату и интервал показываем по фактам. При первой проверке другой конструкции указываем это отдельно. |
| 9. Возврат после перерыва | «Остановились на задаче 3 из 5. Уже решены две». | [Продолжить] · [В меню]. Восстанавливается точная открытая задача с её подсказками и попытками. Если занятия нет — [Персональная тренировка] без списка просроченного. |
| 10. Итог | «Персональная тренировка завершена. Из 5 задач решены 4: три с первой попытки без помощи, одна с подсказкой. В одной открыт разбор. Дроби получились и после перерыва». | [Ещё тренировка] · [Мой прогресс]. Дополнительный аналог после пятой задачи открывает новое занятие. При досрочном выходе отдельно показываем «Пройдено 3 из 5», невыданные задачи исключены. |

При старой кнопке короткий callback-ответ «Эта задача уже завершена. Открой текущую через “Продолжить”». Состояние не меняется. Повторная доставка результата, ошибка сети после записи или быстрое двойное нажатие восстанавливают тот же слот и математический вариант. Пользователь, не выбравший «Ещё похожую», получает следующую задачу планировщика. Два одновременно используемых устройства не создают шестой позиции.

## Мой прогресс

В верхней части одна рекомендация и её основание. Пример: **«Вычитание дробей. В двух разных задачах возникла ошибка. В следующей тренировке будет новый пример»**. Кнопки «Персональная тренировка» и «Подробнее». Далее «Навыки», «По номерам», «История», «Мои ошибки» на экране подробностей. Наступивший срок повторения — атрибут рекомендации. Ранее подтверждённый навык продолжает показывать дату последней проверки.

Во всех строках каталога используем одно оформление «номер · тема / последняя проверка или короткий статус». При отсутствии данных текст занимает то же место. На уровне номера доступны пять последних задач и вкладка типов, сведения о полностью доступных, выключенных и ещё не размеченных номерах различаются. Если известна только семья задачи, вывод «получается в этом типе». Если в семье есть две непохожие постановки, перенос между ними указываем только после проверки новой постановки.

| Пример строки | Что открывается |
|---|---|
| №6 · Вычисления / Есть тема для тренировки | «Вычитание дробей · ошибки в 2 разных задачах» и доступ к каждой |
| №13 · Неравенства / Получается сейчас | «Три новых варианта подряд. Последняя серия 25 ноября» |
| №16 · Окружность / Проверено после перерыва | Дата, интервал, тип задания и доступное следующее действие |
| №22 · Графики / Пока мало данных | Известные баллы и статус проверок при наличии. Рекомендация остаётся пустой, пока основания недостаточны |

Нет круговой шкалы «навык на 67%». Дома ученик может открыть историю восстановленного задания, увидеть исходную ошибку, повтор и новые варианты. В будущей Mini App к тем же данным добавляются фильтры по темам, времени и виду помощи, хронология наблюдений и связи проверенных предпосылок. Telegram самостоятельно показывает все сведения, необходимые для выбора следующей тренировки.

## Игровая петля и голос bop

Ученик видит понятную цель, выполняет пять задач и получает одну короткую сводку. Отметка «Проверено после перерыва» в личной коллекции выдаётся однократно за навык и хранится вместе с датой. Получить её можно независимо от того, были ли ошибки раньше. Сильному доступно подтверждение на новой конструкции. Для ученика, который пользовался помощью, показываем точный личный результат — «Первую задачу решили с подсказкой, следующую — самостоятельно». Признание усилия не требует выдачи валюты. Ошибка, подсказка, разбор, пропуск, пауза и повтор исходника не приносят обмениваемых очков. Факт использования помощи остаётся полезным для планировщика.

Календарная цель факультативна. Недельная цель «два занятия» может показывать фактически завершённые занятия, но в первом релизе её можно исключить. Исчезающие серии, уровни за клики, рейтинги класса, случайные призы и блокировки учебного контента не окупают сложность. Достижения сохраняются, даже когда позже требуется практика. Меняться могут число навыков с актуальной самостоятельной проверкой и выбранные рекомендации. В школьный журнал игровая коллекция не попадает.

bop объясняет учебное событие, говорит коротко и спокойно. При старте достаточно цели; на первой ошибке — оставшейся попытки; после повторных ошибок — предложения сменить представление; после подсказки — конкретного шага; при успехе — «Эту задачу ты решил уже самостоятельно». При возврате информирует о сохранённом слоте. Реплики входят в имеющееся сообщение с результатом. Стикер или короткая анимация — опция только для редкого события и по пользовательскому переключателю, основной смысл доступен текстом.

Меню редактируем через подходящий метод для текущего вида сообщения. При невозможности редактировать создаём один заменяющий экран и атомарно привязываем управляющие действия к его новой ревизии. Условие, подпись к рисунку и управляющее сообщение могут иметь разные ID. Callback получает подтверждение даже при отказе, длину callback_data проверяем по байтам UTF-8 (1–64). Через setMessageReaction бот может поставить до одной реакции, платные реакции недоступны. Собственная emoji-реакция возможна, когда она уже есть на сообщении либо администратор разрешил её в чате. Не обещаем каждому школьнику произвольную реакцию с лицом bop. Доставка стикера и анимации идёт отдельным сообщением, поэтому по умолчанию достаточно текста. [Кнопки](https://core.telegram.org/bots/api#inlinekeyboardbutton), [callback](https://core.telegram.org/bots/api#callbackquery), [редактирование](https://core.telegram.org/bots/api#editmessagetext), [реакции](https://core.telegram.org/bots/api#setmessagereaction), [стикеры](https://core.telegram.org/bots/api#sendsticker), [анимации](https://core.telegram.org/bots/api#sendanimation).

## Что получит учитель

Без нового кабинета достаточно параметризованной выборки за период по разрешённой группе. Колонки: навык, число учеников с независимым наблюдением, число с затруднениями в разных вариантах, число решающих пока только с помощью, число с текущей самостоятельной серией, число с проверкой после перерыва, медиана времени от открытия до текущей серии среди завершивших и число ещё открытых случаев. Отдельно показываем знаменатель «учеников группы всего» и покрытие. Ученик без событий не попадает в группу неуспешных. Групповой пример для урока: «Дроби: 6 из 14 проверенных ошиблись в разных вариантах. Ещё 4 не решали диагностический пример». На уровне ученика учитель видит даты и ссылки на доводы, решение с подсказкой отдельно от собственной проверки и факт выполненного назначения. Оценки и игровые достижения хранятся и интерпретируются отдельно.

## Пилот без запуска

1. До набора утвердить основной исход, задания контроля, распределение, длительность, критерии исключения технического мусора и способ работы с отсутствиями. Отобрать несколько реально доступных навыков с достаточным банком. Для каждого подготовить параллельные формы новой конструкции сходной сложности. Эксперт заранее независимо проверяет эквивалентность и ключи. Контрольные задачи резервируются вне тренажёра. Согласовать школьный порядок информирования семей и учащихся, добровольность, альтернативу без влияния на оценки, доступ учителя и срок удаления соответствия кодов участникам. Платформе исследования достаточно псевдонима, номера группы, событий и времени с точностью, нужной для интервала. Не выгружать имена, чаты и фотографии внешним сервисам.
2. На старте дать общий короткий контроль без подсказок; записать исходный балл и доступное время. При достаточном наборе случайно распределить учеников внутри класса и уровня на обычную тренировку, адаптивную тренировку, адаптивную с отметками bop. Во всех группах сопоставимы время, доступ к подсказкам, диапазон сложности и учебная программа. Сообщения об успехе математически идентичны, между двумя адаптивными группами различается только оформление достижений. Учёт минут и показываемых тем нужен, чтобы различить эффект подбора от разного времени за задачами.
3. Например, четыре учебные недели плюс отсроченная общая проверка через неделю после последней работы по выбранной теме. Дополнительное окно через 3–4 недели, если позволяет расписание. Фиксируем реальную задержку и внешнюю практику по короткому вопросу. Учитель, по возможности, проверяет обезличенные ответы без знания группы. Время, подсказки и правила для контрольной формы одинаковы. Для малой выборки взять две группы «обычная / адаптивная» с исходным балансом, а понятность наград проверить отдельно в интервью и наблюдении. Переключение групп на уже выученном материале даёт перенос, поэтому простое сравнение «до/после смены режима» не идентифицирует эффект.
4. **Основной исход** — доля впервые увиденных задач отсроченной формы, решённых самостоятельно с первой попытки. Сначала агрегировать по ученику. Сравнить адаптивную и обычную группы с учётом входного уровня и класса, дать разности в процентных пунктах и интервалы неопределённости. Малые группы — индивидуальные траектории, интервалы и описание потерь. Вторая пара «адаптивная с игровым оформлением / адаптивная» исследовательская. Участника анализировать в назначенной группе, отказы и пропуски показать отдельно. Для пропущенных проверок дать сценарные границы и число действительно проверенных. Множество попыток одного школьника независимую выборку школьников не увеличивает.
5. Вторичные результаты — повторные ошибки на новом варианте, перенос на иную форму и отношение к подсказкам. Возвращение измерять фактическим добровольным занятием в окнах D7/D28 отдельно от обязательной домашней работы. Для удобства считать завершённые/начатые пятёрки, возвраты к сохранённой задаче, действия от открытия меню до первой выдачи и медиану времени в активной сессии с заранее определённым правилом простоя. Один вопрос после занятия «Понятно, почему тебе предложили эту задачу?» и короткое интервью о желании вернуться. Для интереса отслеживать жалобы на повторы у сильных и циклы неудач у нуждающихся в помощи. Работу с помощью не штрафовать.
6. Техническая приёмка до школьного пилота — каждому видимому статусу соответствует исходная попытка и версия правил; дубли, отключённые семейства и чужие callback не меняют прогресс; на ширинах 360/390/430 доступны полные подписи или короткие равнозначные варианты. Проверить стандартный и увеличенный шрифт на физических Android/iOS, графические и текстовые задания, режим без анимации и слабую сеть. Показана причина недоступности свежего аналога. Пять задач устойчиво заканчиваются даже при отказе генератора с честным фактическим итогом. Зафиксировать отдельно долю ручных подтверждений учителем, спорные диагнозы, повторение свежего варианта и обращение за помощью после новой формулировки интерфейса.
7. Решение о расширении принимает владелец по безопасности, наблюдаемой пользе и цене сопровождения. Стабильная выдача и понятное учащимся объяснение — необходимые условия. При заметном расхождении прогресса с независимой проверкой откатываем публичную формулировку к наблюдаемым фактам и пересматриваем порог. Данные малого пилота позволяют выбрать следующий эксперимент, но сами не устанавливают эффект для всех школьников.

## Независимая продуктовая проверка

| Возражение | Изменение спецификации |
|---|---|
| Два ответа к одной задаче могут отражать один неверно понятый рисунок | Маркируем «стоит проверить». Для устойчивого затруднения ищем повторение на независимом варианте и диагностируем причину по отдельному простому заданию |
| Обязательная дата повторения конфликтует с намерением школьника продолжать сейчас и с решением #110 | Сохраняем немедленную следующую пятёрку, а повторение добавляем при ближайшем визите после срока. Сам пропуск дня статуса не меняет |
| «Ещё похожую» позволяет вытеснить остальные слабые темы | Следующий слот добровольно отдан тому же навыку, число слотов фиксировано. В следующей рекомендованной пятёрке остальные темы возвращаются |
| Исчерпан маленький банк. Три разные записи имеют одну математику | Считаем видимые математические варианты и тип конструкции, не число task_id. Нехватку материала показываем как ограничение банка |
| Карта всех школьных тем выглядит убедительнее, чем позволяет разметка | Начинаем с карточки семейства и считанных проверенных связок. В деталях можно посмотреть конкретные задачи, которые послужили основанием |
| Сильный школьник может решать один тип ради награды | Одна отметка на навык, накопление через бесконечное повторение отсутствует. Непроверенная конструкция даёт осмысленную новую цель |
| Ученик избегает подсказки, опасаясь потери достигнутого | Объясняем, что помощь доступна, прежние подтверждения и отметки сохраняются. Новую самостоятельную проверку выдаём позже. Отслеживаем снижение использования помощи и интервьюируем учеников |
| Много красивых экранов усиливает трение | Старт за два нажатия из главного меню, продолжение за одно. В пилот берём одну отметку, одну рекомендацию и короткую историю. Коллекционный экран, уровни, push и панель администратора можно отложить |
