## Как дать задание Codex Cloud

Материалы опубликованы в ветке `docs/geometry-15-19-codex-handoff`, а не в `main`. При запуске Codex нужно либо выбрать эту ветку как исходную, либо явно прочитать документы командой `git show` с `origin/docs/geometry-15-19-codex-handoff` из рабочей ветки, созданной от свежей `main`.

Первый PR реализации должен остаться независимым от изменений интерфейса PNG-прогресса. Не выполнять merge, deploy и публичное включение геометрии без отдельного решения.
