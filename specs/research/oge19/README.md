# OGE Bot — исследование №19

Содержимое `RESEARCH.md`, `SOURCE_MATRIX.json` и `RESEARCH_GATES.md` фиксирует исходное исследование 39 прототипов и границы верификации. Это исследовательские данные, а не инструкции для разработки.

- `RESEARCH.md`: исследование 39 прототипов.
- `SOURCE_MATRIX.json`: матрица оригинальных карточек с уровнем проверки.
- `RESEARCH_GATES.md`: контрольные темы, ограничения и маски источников.

Текущий объём и пределы покрытия описаны в [OGE19_COVERAGE.md](../../coverage/OGE19_COVERAGE.md). Для дополнительных высказываний источником служит проверенная математическая конструкция, а не заявление о дословной цитате из карточки.
