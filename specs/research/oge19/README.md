# OGE Bot — автономные материалы по №19 для Codex

Материалы в ZIP не требуют GitHub или доступа к дополнительной ветке:

- `OGE19_RESEARCH.md`: исследование 39 прототипов.
- `OGE19_SOURCE_MATRIX.json`: матрица 39 оригинальных номеров с уровнем проверки.
- `OGE19_RESEARCH_GATES.md`: фрагмент итогового реестра №19, ограничения и контрольные ответы.

Не приравнивать исторические маски к актуальному экзаменационному формату без сверки с ФИПИ. Не считать автоматически подтверждёнными 25 аналитически разобранных прототипов. Приоритет: 80–120 доказанных утверждений из реальных тем ОГЭ, без векторов и лишних перефразировок.

Если Codex не имеет сети, он может разрабатывать предметные модули и запускать локальные проверки, но физически не сможет создать GitHub PR. В таком случае сохранить изменения и выдать patch или diff для последующей публикации. Не выдавать работу как PR до фактической публикации.
