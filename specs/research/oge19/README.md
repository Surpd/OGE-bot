# ОГЭ №19 — пакет для реализации банка геометрических утверждений

Этот каталог переносит исходное исследование **прямо в `main`**. Он создан специально для облачного Codex, который может не иметь доступа к дополнительным GitHub-веткам.

## Файлы

- [RESEARCH.md](RESEARCH.md) — исследование 39 прототипов и 15 тематических групп из банка «РЕШУ ОГЭ» (5 ноября 2026).
- [SOURCE_MATRIX.json](SOURCE_MATRIX.json) — каталоговые ID, ответы, маски и уровень индивидуальной проверки. Это **не** сертифицированный банк для публичной выдачи.

## Важные ограничения

1. В матрице 39 прототипов, но только часть ответов независимо сверена с опубликованными решениями. `catalog_analyzed` **не** эквивалент `verified_answer`.
2. Классификации G01–G15 — тематические области, а не готовые независимые генераторы или 15 обязательных семейств.
3. Источник №461001 содержит рассогласование между инструкцией и маской ответа; нельзя автоматически копировать его формат.
4. Формат №19 в утверждённых документах ФИПИ-2027 нужно сверять отдельно: исторические задания могут иметь несколько верных пунктов; не смешивать формат одного верного с несколькими.
5. Целевой первый банк — **80–120 качественных, содержательно различных утверждений**, не произвольные 300. Содержание — реальная геометрия ОГЭ 7–9 классов; приоритет темы до конца 8-го. Не добавлять векторы, сложную геометрию и внеэкзаменационные формулировки ради количества.
6. Для TRUE обязательно корректное краткое объяснение, для FALSE — корректный контрпример или доказательство невозможности. Простая проверка непустого `proof` не подтверждает истинность.
7. Нужен детерминированный сборщик троек по версии банка и seed; только независимо проверенные атомы допускаются к выдаче.
8. Параллельно идут PR по №15–17. Не редактировать их модули, Telegram `router/menu/training_engine/trainings`, persistence, миграции или прогресс. Реализацию №19 делать отдельным математическим PR без публичного включения.

Источники: [каталог РЕШУ ОГЭ](https://math-oge.sdamgia.ru/test?category_id=15&filter=all&ttest=true), [ФИПИ](https://fipi.ru/oge/demoversii-specifikacii-kodifikatory).
